## MarkLeaf でできること

MarkLeaf は、主に Markdown を使って文章を作成・レイアウトするためのテキストエディターです。Markdown は簡単な記号で文書の構造を表します。ビジュアルモードでは、メニューや段落書式ボタンからこれらの操作を行えます。よく使う操作にはおなじみのキーボードショートカットもあります。ショートカットを使うと、これらの機能をより快適に利用できます。

### 見出し

ビジュアルモードでは、メニュー項目または段落書式ボタンから見出しを設定できます。`#` の後にスペースを入力すると、その段落が自動的に見出しへ変換されます。

ソースモードでは、文字の前に `#` を追加して見出しを作成します。`#` の数が見出しレベルを表します。例：

```markdown
# 見出し 1
## 見出し 2
### 見出し 3
```

見出しは自動的にアウトラインに表示されます。アウトライン項目をクリックすると、対応する章へ移動できます。

### インライン書式

- `**太字**` は **太字** と表示されます
- `*斜体*` は *斜体* と表示されます
- `***太字斜体***` は ***太字斜体*** と表示されます
- `~~取り消し線~~` は ~~取り消し線~~ と表示されます
- `++下線++` は ++下線++ と表示されます
- `==ハイライト==` は ==ハイライト== と表示されます

文字を選択した後、「書式」メニューまたはコンテキストメニューでこれらのスタイルを適用できます。エディターで対応する記号を閉じた形で入力すると、囲まれた文字も自動的に対応する書式になります。

### リスト

Markdown には三種類のリストがあります。

#### 箇条書きリスト

`-` を接頭辞として使うリストです。

- アイデアを記録する
- 関連資料を整理する
- 初稿を完成させる

#### 番号付きリスト

`1.` を接頭辞として使うリストです。

1. 内容を書く
2. 書式を確認する
3. 保存してエクスポートする

#### タスクリスト

`[ ]` を接頭辞として使うリストです。\[x\] はタスクが完了したことを表します。

- [x] MarkLeaf をインストールして開く
- [ ] 最初の文書を作成する
- [ ] HTML または PDF へのエクスポートを試す

リスト項目にカーソルがあるとき、`Tab` でインデントを増やして子項目にしたり、`Shift+Tab` でインデントを減らしたりできます。

### 引用とコードブロック

`>` を使うと引用ブロックを作成できます。`>` の数が引用レベルを表します。引用ブロックの文章は次のように表示されます。新しい行で大なり記号を入力し、スペースを押して、書式がどう変わるか試してみてください。

> 夕暮れの涙が出そうな赤、私の中の君の溶かしてしまえ。

3 つのバッククォートを使うとコードブロックを作成でき、先頭で言語を指定できます。

```python
message = 'Hello, MarkLeaf!'
print(message)
```

### 表

メニューから、または `Ctrl+T` を押して表を作成し、次のように内容を編集できます。

> tablecaption: **表 1：** MarkLeaf の主な機能


| 機能      | 用途                        |
| ------- | ------------------------- |
| ビジュアル編集 | Markdown 記号を常に扱わず、内容に集中する |
| ソース編集   | Markdown テキストを正確に制御する     |
| ワークスペース | 同じフォルダー内の複数の文書を管理する       |
| アウトライン  | 見出し構造を確認してすばやく移動する        |

表内にカーソルを置くと、表メニューから行や列の追加・削除、配置の調整ができます。他のエディターとは異なり、ここでは表に**キャプションを設定**できます。コンテキストメニューの「表キャプションを編集」を試してみてください。

### インライン数式

LaTeX の内容を一対の閉じたドル記号で囲むと、インライン数式を挿入できます。たとえば、`$E=mc^2$` は次のように表示されます：$E=mc^2$。

もう一つの例は、三平方の定理です：$a^2+b^2=c^2$。

> この数式の左右にドル記号を一つずつ入力して、どう変わるか試してみてください！
>
> \\int\_a^b f(x) \\, dx = F(b) - F(a) = F(x) \\Big|\_a^b

### ブロック数式

長い数式は独立した段落にできます。左右をそれぞれ二つのドル記号で囲みます。

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

メニューから数式を挿入することも、LaTeX のソースを直接入力することもできます。数式を右クリックすると、ブロック数式とインライン数式を切り替えられます。

### 脚注

本文に `[^1]` のような閉じた脚注参照を入力すると、MarkLeaf はそれを上付き文字として表示します。脚注の定義は段落の先頭に置きます。

これは補足説明を含む文章です[^1]。

[^1]: 脚注には **太字**、*斜体*、`インラインコード` を含められ、インライン数式 $x^2+y^2$ も使用できます。本文の脚注番号にマウスを合わせるとプレビューを確認できます。

脚注参照を `Ctrl` を押しながらクリックすると定義へ移動できます。脚注定義を `Ctrl` クリックすると参照へ戻れます。

### Mermaid 図

MarkLeaf は、言語に `mermaid` と指定したコードブロックを対応する図としてレンダリングできます。

```mermaid
flowchart LR
    A[執筆を始める] --> B[構成を整理する]
    B --> C[内容を確認する]
    C --> D[保存またはエクスポート]
```

メニューから空の Mermaid 図を挿入し、ソースを入力してレンダリングできます。図を再編集して更新することもできます。

## MarkLeaf を快適に使う

### レイアウトスタイルとカラーテーマ

「表示 &gt; レイアウトスタイル」を使うと、レンダリングされた Markdown テキストのレイアウトを変更できます。それぞれのスタイルには独自の特徴があります。たとえば：

- 印刷物スタイルでは、紙の本のような見た目になります。
- LaTeX スタイルでは、LaTeX でレンダリングしたような見た目になります。

さらに、暗いテーマと明るいテーマを含む数十種類のプリセット配色を用意しています。気に入ったものを選んで試してみてください！

実は、すべてのテーマは CSS ファイルです。つまり、自分でレイアウトスタイルやカラーテーマを作成できます。形式に合ったテーマをテーマフォルダーに置けば、自動的に認識されます。

### 段落書式ボタン

段落にマウスを合わせると、左上に小さな長方形のボタンが表示されます。クリックすると、段落や書式に関する多くのショートカットが表示されます。これを使って段落の書式をすばやく調整してください。

### 最小モード

`F11` を押すと最小モードに切り替わります。このモードでは文章だけが表示され、ほかの要素による干渉がないため、書くことに集中できます。終了するには、もう一度 `F11` または `Esc` を押します。

### 集中モードとタイプライターモード

`F8` を押すと集中モードになります。集中モードでは現在の段落以外の段落が薄く表示され、現在の内容に集中しやすくなります。`F9` のタイプライターモードでは、カーソルが常に画面の中央に保たれます。

### サイドバーを使う

フォルダーを開くと、ワークスペースにその中の Markdown とプレーンテキストの文書が一覧表示されます。次の操作ができます。

- ファイルやフォルダーを作成する
- ダブルクリックして文書を開く
- ファイル名の場所で直接名前を変更する
- ツリー構造でディレクトリを確認する、または文書一覧に切り替える
- アウトラインで現在の文書の見出しを確認する
- アウトラインをウィンドウ右側に分離して、幅を独立して調整する

サイドバーの表示状態とウィンドウサイズは自動的に保存され、次回起動時に前回の状態を復元できます。アウトラインをワークスペースから分離することもできます。

### 保存、エンコーディング、エクスポート

ステータスバーには現在のファイルのエンコーディング、改行コード、ズーム率が表示されます。これらをクリックすると、それぞれのメニューを開けます。

ファイルのエンコーディングを変更するとき：

- 「直接読み取り」は、選択したエンコーディングでファイル内容を再解釈します。
- 「エンコーディングを変換」は、現在の文字内容を保ったまま、選択したエンコーディングで保存します。

迷った場合は「エンコーディングを変換」を優先し、変換前に重要な内容を保存してください。

「ファイル &gt; エクスポート」から、閲覧、共有、印刷に適した形式へ文書をエクスポートできます。エクスポート内容には、表、数式、脚注、Mermaid 図など、対応している機能が保持されます。<strong>「印刷物」または「LaTeX」でのエクスポートも試してみてください。文書が印刷や読書により適した見た目になります！</strong>
