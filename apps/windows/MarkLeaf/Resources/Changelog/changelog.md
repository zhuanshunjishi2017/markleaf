# MarkLeaf 更新内容

## 版本：v1.7.0

更新时间：2026-9-3

### 新增

- 新增多标签页编辑，可在同一窗口同时打开多个 Markdown 或纯文本文档，并为每个标签页独立保留未保存内容、只读状态和编辑状态
- 新增标签页会话恢复，关闭应用时记录所有具有真实路径的打开文档及当前标签页，下次启动时恢复完整标签页集合
- 新增标签页切换快捷键：`Alt+1` 至 `Alt+9` 切换前九个标签页，`Ctrl+Tab` 循环切换到下一个标签页
- 新增标签页关闭快捷键：`Ctrl+W` 关闭当前标签页，`Ctrl+Shift+W` 关闭其他标签页
- 新增「查看 > 标签页管理」子菜单，动态列出所有打开的标签页，并提供下一个标签页、关闭当前标签页、关闭其他标签页和在工作区定位文档命令
- 新增标签页原生右键菜单，支持关闭标签页、关闭其他标签页、关闭右侧标签页、在工作区定位文档、复制文件路径和打开文件所在的位置
- 新增标签页拖动排序，越过相邻标签页中点时自动交换位置，并为交换和归位过程提供平滑动画
- 新增将标签页拖出窗口的功能，可在新窗口中打开该文档并保留未保存内容、只读状态、编码和换行符等编辑状态
- 新增标签页横向滚轮浏览，标签页过多时可在标签栏内使用鼠标滚轮左右滚动
- 新增标签页状态标识，可显示「外部」或「只读」；未保存文档使用关闭按钮位置的圆点标记，悬停时恢复关闭图标
- 新增编辑器全屏模式，快捷键为 `F11`，可通过再次按下 `F11` 或 `Esc` 退出；最简模式快捷键调整为 `Shift+F11`
- 新增「在标签页栏显示菜单」菜单样式，可在普通窗口中隐藏顶部菜单栏并将菜单入口放入标签页栏
- 新增标签页栏自适应菜单：空间足够时显示文件、编辑、段落、格式、查看和帮助六个菜单，空间不足时收起为统一菜单按钮
- 新增标签页栏右侧新建按钮，可直接执行新建 Markdown 文档命令
- 新增原生菜单悬停切换行为，打开一个顶级菜单后，将鼠标移动到其他顶级菜单即可直接切换
- 新增「重复该段」和「删除该段」命令，可从段落格式菜单复制或删除当前段落
- 新增 Markdown 符号转义设置，可分别控制是否将 `&`、`<`、`>` 等符号转换为 HTML 实体，以及是否为 `*`、`_`、`\` 等字面量添加反斜线转义

### 更改

- 新建命令不再显示 Markdown 与纯文本子菜单，`Ctrl+N` 现在直接新建 Markdown 文档
- 工作区右键菜单中的「新建文件」改为直接命令，不再使用文件类型子菜单
- 编辑器初始化完成后不再自动建立空白文档；没有文档打开时保持空编辑区状态
- 打开、新建和恢复文档统一使用标签页承载；再次打开已经存在的文档时直接切换到原标签页
- 关闭应用时会遍历全部打开文档；存在一个或多个未保存文档时统一询问保存或丢弃，并可批量保存所有修改
- 关闭全部标签页后清空编辑器、工作区选中状态和大纲；状态栏只保留侧栏显隐按钮
- 标签页采用固定最大宽度，空间不足时平滑压缩；标签页名称使用省略号显示，同时保证只读、外部和关闭状态区域始终可见
- 标签页出现、关闭、排序和尺寸变化使用位置与宽度插值动画；鼠标位于标签页栏内时暂缓重新计算宽度，便于连续关闭
- 拖出的新窗口按照鼠标释放位置和原编辑器尺寸创建，默认不打开工作区并收起侧栏
- 全屏模式保留窗口其他界面元素，并沿用最大化窗口的侧栏行为；全屏下仍可进入最简模式
- 最简模式会隐藏标签页栏，但仍可通过键盘切换标签页
- 标签页栏菜单展开阈值调整为四个最大宽度标签页的总宽度；没有标签页时始终显示完整菜单
- 标签页栏菜单打开时使用选中背景色，并缩小展开菜单按钮的间距和水平留白
- 重新整理段落格式菜单：水平线移动到代码块下方，提示框改为子菜单，插入表格移动到列表上方，并在标题和引用区域补充分隔及段间公式命令
- 调整编辑器原生右键菜单，顶部加入行内代码、行内公式、插入超链接和插入图片命令；插入图片改为本地图片与网络图片子菜单
- 调整前端格式菜单，加入删除线按钮，将格式刷移至清除格式左侧，并补充对应分隔线
- 工作区定位文档时会自动打开目标文档、切换到树视图、展开侧栏并切换至「文件」视图；无真实路径或不在工作区内的文档禁用该命令
- 工作区内文件重命名后同步更新所有对应标签页名称；删除当前文件后在原标签页中建立干净的未命名文档
- 未打开工作区时重新设计「打开文件夹」按钮，使用主题选中背景、粗体文字并移除文件夹图标
- 侧栏搜索框高亮边框改为完全跟随输入框焦点，获得焦点时显示，失去焦点时立即隐藏
- 默认图片缓存目录由 `Cache` 根目录调整为 `Cache\image`；旧默认路径自动迁移，欢迎文档、更新日志和标签页传输状态仍保存在 `Cache` 根目录
- 删除尚未实现的图片上传处理选项及运行时分支，保留图片上传配置区域和未完成功能提示
- 图片相对路径仅在图片位于 Markdown 文档同目录或子目录时生成；位于上级目录或其他位置时保留原路径
- 图片路径中的空格仅编码为 `%20`，中文及其他 Unicode 字符保持可读形式；同时支持解析带空格和带 `./` 前缀的相对图片路径
- Markdown 序列化默认保留 `&`、`<`、`>` 等字面符号，并确保代码块、行内代码、行内公式、行间公式和链接目标不参与普通文本转义
- 强调标记转换为 HTML 时先序列化完整 Markdown，再使用 CodeMirror Markdown 语法树判断粗体、斜体及粗斜体的真实解析结果和精确闭合边界
- 源码模式下未被解释的星号提示改为读取 Markdown 语法树；已被高亮解析为粗体或斜体的标记不再提示
- 脚注定义正文单独建立 Markdown 语法树并映射回全文坐标，使脚注中的粗体、斜体能够参与准确的序列化判断
- 显示公式跟在列表项之后时，序列化结果会自动在列表与公式之间加入空行，使公式正确退出列表并独占段落
- 更新四种语言的标签页、全屏、菜单样式、段落命令、符号转义和工作区定位文本，并同步更新欢迎文档中的全屏与最简模式快捷键说明

### 修复

- 修复切换标签页时未保存编辑内容丢失、脏状态互相干扰或保存到错误文档的问题
- 修复关闭单个或多个未保存标签页时，选择保存后文件未保存且窗口无法关闭的问题
- 修复应用启动时只恢复单个文件、没有工作区便无法恢复文件，以及编辑器就绪后错误新建空白文档的问题
- 修复关闭最后一个标签页后工作区选中状态和大纲未清空的问题
- 修复关闭当前标签页右侧的标签页时界面不刷新，必须再次切换标签页才消失的问题
- 修复标签页关闭按钮按下和抬起不在同一区域时仍会误触关闭的问题
- 修复标签页动画卡顿、阻塞切换或关闭、删除标签页后宽度锁定不释放以及动画期间重复参与布局计算的问题
- 修复标签页拖动无响应、交换时没有动画、拖动项被其他标签页覆盖以及松手后全部标签页重复动画的问题
- 修复标签页拖出窗口后位置偏移、编辑器尺寸变化、错误继承工作区或侧栏状态的问题
- 修复低 DPI 环境下标签页和工作区图标边缘被裁切的问题
- 修复标签页过多时越过可视区域并遮挡右侧新建按钮的问题；标签页绘制现在严格裁剪在菜单与新建按钮之间
- 修复首次进入全屏后打开菜单会出现无效菜单句柄的问题
- 修复全屏且没有标签页时菜单入口不显示，以及普通菜单模式下右侧新建按钮缺失的问题
- 修复全屏模式下侧栏仍按普通窗口宽度补偿、导致窗口或编辑区域尺寸异常的问题
- 修复「最简模式」的 `Shift+F11` 快捷键未生效或未显示在菜单中的问题
- 修复工作区定位新建未保存文档时因不存在真实路径而错误执行的问题
- 修复文件名包含空格、中文或 `./` 前缀时相对图片无法加载的问题
- 修复启用相对路径后错误引用 Markdown 文档上级目录中的图片，以及复制图片后未按最终位置判断相对路径的问题
- 修复公式编辑浮层输入全角标点时光标跳转到段落末尾的问题
- 修复紧跟列表的行间公式被当作列表项硬换行而无法渲染的问题
- 修复 Markdown 星号提示将 `**粗体***斜体*` 等相邻合法强调标记误报为未解释语法的问题
- 修复序列化将合法的嵌套强调和局部粗斜体转换为 HTML，例如 `***粗斜体*粗体**`；现完全依据语法树节点及闭合范围保留标记
- 修复粗体或斜体跨越两个段落时被错误转换为 HTML 标签的问题
- 修复禁用普通符号转义时破坏 Markdown 代码、公式或链接结构的问题
- 修复 HTML、PDF 和图像导出未应用中文与西文、数字自动间距装饰的问题；导出现在使用与可视化编辑器相同的间距元素，并排除代码、公式和 Mermaid 内容
- 修复源码编辑器高亮刷新干扰输入法提交位置，导致全角标点输入后光标异常移动的问题
- 修复侧栏搜索框在单击树视图空白处、标签切换区、编辑器或窗口失焦后仍保持高亮的问题

## 版本：v1.6.2

更新时间：2026-9-2

### 新增

- 新增 Markdown 语法设置标签页，可配置代码围栏、粗体与斜体、无序列表的规范化标记偏好
- 新增末尾空段落按下回车时退出块和使用 `Shift+Enter` 硬换行的可选设置
- 新增源码模式下未被解释的星号标记处理选项，可选择提示、保留字面量或自动转换
- 新增可视化编辑器在段首按 `Tab` 或输入四个空格时转换为代码块的支持
- 新增硬换行后的 Setext 标题语法输入转换支持
- 新增 Mermaid 源码语法高亮

### 更改

- Markdown 规范化改为由解析器直接按照首选项输出代码围栏、强调标记和无序列表标记，不再进行简单文本替换
- 支持使用下划线作为强调标记，并保留单词内部下划线的字面含义
- 中文与西文字符、数字之间的可视化自动间距调整为半角空格宽度，不修改原始 Markdown 内容
- 源码模式中文字体和英文字体支持直接输入自定义值，并在设置中持久化保存
- 工作区文档列表增加文档开头的纯文本预览；搜索结果统一使用去除 Markdown 标记后的纯文本，并从匹配位置前两个字符开始显示
- 工作区预览内容限制为打开工作区时读取的前 2 KB，并使用缓存，文件变化后重新生成对应预览
- 点击搜索结果中的正文匹配项后，打开文档并自动打开查找界面定位搜索内容
- 优化文档列表虚拟化绘制、滚动和悬停刷新逻辑，减少列表滚动时的重复重绘
- 同步补充四种界面语言的 Markdown 语法设置文本和搜索、文档预览相关文本

### 修复

- 修复反向输入 Markdown 标记无法识别以及识别后光标位置错误的问题
- 修复可视化编辑器输入闭合下划线强调标记时无法自动转换的问题
- 修复水平线难以选中的问题，现在点击水平线所在行的任意区域即可选中
- 修复代码块、引用块及提示框在末尾空段落按空格退出逻辑未受设置控制的问题
- 修复 Mermaid 和代码块的 Markdown 输出未遵循代码围栏首选项的问题
- 修复文档列表滚动卡顿、悬停导致全部文档重绘以及滚动条存在与否造成卡片宽度不一致的问题
- 修复搜索结果与文档列表标题、日期右边界和右侧间距不一致的问题
- 修复文件变化后文档预览缓存未及时失效的问题
- 增加 Markdown 语法设置、文档预览缓存和搜索纯文本匹配的测试覆盖

## 版本：v1.6.1

更新时间：2026-9-1

### 新增

- 新增长图导出，可从「导出 > 图像」或导出窗口的「图像」标签生成 PNG、JPEG 图片
- 图像导出支持设置单张最大高度、内容宽度、输出倍率、JPEG 质量、排版样式和配色方案；超过最大高度时自动拆分为多张图片
- 首选项「通用」新增「更新」类别，可手动检查更新，并可选择在应用启动时静默检查新版本
- 首选项「外观 > 窗口」新增菜单显示设置，可分别控制菜单中的键盘快捷键和非英文助记键是否显示
- 公式空内容新增可视化占位符 `...`；浮层编辑区仍保持为空，Markdown 以 `$...$` 或 `$$...$$` 持久化并可重新识别为空公式
- 公式浮层支持 `Esc` 收起，收起后将焦点和光标恢复到公式节点之后
- 公式浮层内新增独立的全选、剪切和粘贴键盘行为，操作范围只限于浮层源码
- 扩充公式测试，覆盖空公式占位、行内/行间公式转换、浮层编辑及 Markdown 往返
- 扩充提示框测试，覆盖提示框内多个独立段落的解析和序列化

### 更改

- 重构首选项窗口布局，外观和编辑类别使用带动画的自绘分段标签，文件、图片和通用类别统一使用主题化选项容器
- 首选项改为在单击「确定」后统一写入设置，单击「取消」不会应用本次修改
- 将源码模式的中西文字体与字号设置直接嵌入首选项，不再打开独立字体窗口
- 将默认浅色、深色配色方案设置并入「外观 > 主题」，移除独立的默认主题窗口
- 调整首选项窗口尺寸、选项分组、间距、按钮和容器配色，使其与当前主题及侧栏切换控件保持一致
- 菜单文本统一通过通用格式化逻辑处理；可隐藏右侧快捷键及非英文界面括号内的助记键，英文助记键保持原有显示
- 调整多项菜单助记键：最简模式使用 `M`，重启编辑器使用 `E`，段前插入行使用 `U`，段后插入行使用 `B`；「复制/粘贴为」不再设置助记键
- 首选项中的「检查更新」按钮使用助记键 `U`
- 图像导出格式改用 PNG/JPG 单选按钮，JPEG 质量改用带数值标签的滑块
- 图像导出预览只在内容宽度、排版样式或配色方案改变时刷新；格式、质量、倍率和分割高度只在实际导出时生效
- HTML 与图像预览隐藏滚动条，图像内容宽度和两侧边距按照编辑器排版设置生成
- 公式命令会根据当前选中的公式执行编辑或类型转换：相同类型打开浮层，不同类型在行内公式与行间公式之间直接转换
- 提示框支持保留多个独立段落，不再将段落间空行统一转换为硬换行
- 默认提示框正文缩进继承引用块样式；仅 LaTeX 主题强制取消缩进并使用 tcolorbox 风格
- Print 主题提示框改为引用框式外观，在顶部居中显示类型标题；引用框上下内边距与左右内边距保持一致
- 微调 Apple Blue 配色主题的悬停、选中和强调色
- 四种界面语言同步补充图像导出、首选项分组、菜单显示和自动更新相关文本

### 修复

- 修复选择「恢复上次工作区和文件」时，未保存有效工作区便不会恢复上次打开文件的问题
- 修复公式浮层打开时粘贴内容会落入正文并替换公式节点的问题
- 修复公式浮层内 `Ctrl+A` 全选整篇文档，以及 `Ctrl+X`、`Ctrl+V` 未作用于浮层的问题
- 修复只读文档中的公式源码浮层仍可剪切、粘贴或拖动编辑的问题
- 修复公式浮层外层容器与代码块圆角不一致，导致阴影呈直角矩形的问题
- 修复 Mermaid 即时渲染后源码浮层仍按错误提示框旧高度定位、意外向上移动的问题
- 修复图像导出内容右侧出现巨大空白、左右边距不一致的问题
- 修复图像导出设置区域因控件宽度和网格布局造成的排版错乱
