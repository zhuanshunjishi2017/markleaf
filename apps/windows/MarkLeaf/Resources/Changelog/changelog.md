# MarkLeaf 更新内容

## 版本：v1.2.2

更新时间：2026-8-15

### 新增

- 新增「格式刷」命令：右键菜单与格式菜单均可使用，快捷键 Ctrl+Shift+C，复制当前文本格式并应用到选中文本，再次点击取消
- 新增「以只读方式打开」文件入口；只读文件编辑器不可编辑，标题栏显示「（只读）」后缀，段落格式按钮自动隐藏
- 更新内容窗口以只读方式打开，避免误编辑
- 插入表格改为 Word 式网格选择器：悬停预览行×列后点击插入，支持自定义行列数
- 首选项编辑器新增「显示段落格式按钮」开关
- 状态栏新增「源码 / 可视化」切换按钮

### 更改

- .txt 文档以纯文本源码模式打开，源码/可视化切换对其禁用
- 图片旋转统一为「百分比宽度 + 宽高比」模型：旋转仅取宽高比倒数、保持设定宽度不变

### 修复

- 修复切换语言时查找栏按钮与「标+」「标-」不刷新、显示空白的问题
- 修复段落格式按钮在列表/任务列表内显示、污染正文文本的问题
- 修复导出 PDF 图片按原始尺寸渲染、不按设定百分比宽度显示的问题
- 修复导出 PDF 图片靠左、未居中显示的问题
- 修复导出 PDF「全宽」图片比例变形的问题（保持原始宽高比）
- 修复编辑器横向图片旋转 90° 后上下留白、图片被压缩的问题

## 版本：v1.2.1

更新时间：2026-8-14

### 新增

- 可视化模式右键菜单改为前端 + 原生混合菜单：选中可设置格式的文本时，前端在鼠标位置显示粗体/斜体/下划线按钮（Segoe Fluent Icons 图标、原生风格、淡入淡出），下方原生菜单同步显示/隐藏
- 标题场景下前端格式菜单增加「标+」「标-」按钮，对应提升/降低标题等级
- 新增「清除段落格式」命令（助记键 F），将当前段落转为正文并清除加粗/斜体/删除线/下划线/行内代码/行内公式等格式
- 右键菜单新增「段落格式」父菜单（复用段落手柄菜单）、「复制为」子菜单（复制 Markdown 源码 / 复制纯文本）、「全选」
- 双击公式打开公式编辑窗口并自动填充当前公式内容
- 图片右键菜单支持更改图片、重设图片大小（全宽/50%/75%/90%）、顺时针旋转 90 度、图片另存为
- 图片宽度改为按页面宽度百分比记录，窗口缩放时实时重算

### 更改

- 下划线、删除线命令在无选区时也作用于整段，与粗体/斜体一致
- 段落手柄菜单底部新增「清除段落格式」
- 调整排版样式字体回退（latex、复古印刷移除"汉仪中黑简"）

### 修复

- 修复切换语言时侧边栏搜索框提示文本不立即刷新的问题
- 修复「清除格式」不删除段落内行内格式的问题
- 修复图片宽度仅在触及边缘时才更新、未实时响应窗口尺寸变化的问题

## 版本：v1.2.0

更新时间：2026-8-13

### 新增

- 支持 LaTeX 数学公式：行内 `$...$` 与块级 `$$...$$`，可视化编辑输入闭合公式后自动渲染（KaTeX）
- 段落菜单新增"段间公式"、格式菜单新增"行内公式"命令；选中文本时直接套公式标记，未选中时弹框输入
- 公式右键菜单支持编辑、行内/块级互转、删除
- 右键菜单按上下文动态变化：源码模式、表格、公式、标题、代码块分别显示对应操作
- 导出 HTML/PDF 支持数学公式渲染（自包含 KaTeX CSS 与字体，仅打包 woff2 减小体积）

### 更改

- 印刷排版响应"最大宽度"限制，与网页排版一致
- PDF 导出表格宽度随内容变化，内容过宽时才占满页边距
- 段落左侧操作按钮在表格中显示"表"

## 版本：v1.1.5

更新时间：2026-8-12

### 新增

- 首选项编辑器新增"汉字优先字型"选项，可选择简/繁/日/韩汉字在字体中的优先字形变体
- 视图菜单新增"专注模式"入口，快捷键 F11 进入、Esc 退出
- 编辑器字体设置合并为独立"字体设置"对话框，支持中文字体、西文字体、字号统一配置
- base.css 和 sans.css 新增思源宋体 CN / 思源黑体 CN 作为回退字型

### 更改

- 大纲字号缩小为 9pt，取消选中项背景色，未选中项使用次要文字颜色

### 重构

- MainForm 按职责域拆分为 14 个 partial 文件（外观、命令、对话框、编辑器、日志路径、菜单、设置、侧栏、窗口）
- 工作区模块拆分为 6 个 partial 文件（核心、菜单、排序、最近项、条目CRUD、文件监控）

## 版本：v1.1.1

更新时间：2026-8-9

### 新增

#### 编辑

- 可视化编辑 Markdown，支持标题、加粗、斜体、删除线、行内代码、链接、图片，
有序列表、无序列表、任务列表、引用块、代码块、水平线、表格
- 源码模式（纯文本），可切换回可视化模式
- 查找和替换，支持大小写匹配、全词匹配
- 撤销/重做
- 剪贴板图片粘贴、拖入图片

#### 界面

- 系统原生菜单栏
- 侧边栏：工作区文件树、文档大纲
- 状态栏：字数、行列位置、编码、换行符、编辑模式、缩放百分比

#### 文件

- 新建、打开、保存、另存为
- 打开文件夹作为工作区
- 安全保存（先写临时文件再替换）
- 自动恢复（崩溃后重新打开可恢复）
- 检测外部修改（提示而非静默覆盖）
- 自动保存（可选）
- 最近文件和最近文件夹记录

#### 主题

- 内置 17 种颜色主题
- 内置 10 种排版样式
- 跟随系统颜色模式自动切换
- 可导入自定义主题 CSS 文件
- 深色模式下菜单栏同步变深

#### 导出

- 导出为 PDF（可选纸张大小、方向、页边距）
- 导出为 HTML
- 导出时保留颜色主题和排版样式

#### 多语言

- 简体中文
- 繁體中文
- English
- 日本語

#### 首选项

- 启动操作、保存选项、换行风格、历史记录
- 排版样式、配色方案、颜色模式、窗口置顶、隐藏滚动条、菜单栏样式
- 编辑器字体/行高/宽度设置、中文字体和西文字体独立选择
- 图片保存方式和默认目录

#### 安装

- 提供 MSI 安装包
- 支持 x64、x86、arm64

### 修复

- 快捷键在编辑器获得焦点时失效
- 中文输入法导致文字重复和光标跳转
- 外部修改文件被静默覆盖
- 深色模式下状态栏颜色覆盖不全
- PDF 导出页边距为白色
- 切换语言后部分提示文字显示异常
