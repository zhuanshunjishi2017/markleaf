# MarkLeaf 更新内容

## 版本：v1.5.1

更新时间：2026-8-28

### 新增

- 新增工作区/大纲切换动画，使用主题滑块平滑移动并同步调整宽度；动画期间可再次切换并反向播放
- 脚注定义支持加粗、斜体、删除线、下划线、行内代码、链接和行内公式等行内内容
- 帮助菜单新增「欢迎」，会将欢迎文档复制到缓存目录并以可编辑 Markdown 文档打开

### 更改

- 脚注定义保存时保留正文中的行内 Markdown 格式，鼠标悬停脚注引用时以纯文本显示内容和公式源码
- 脚注定义中的行内公式使用 KaTeX 渲染，并支持直接输入闭合的 `$...$` 公式
- 代码块和行内代码中的图片语法不再参与图片缺失检测、路径规范化或图片路径替换
- 欢迎文档加入 Markdown 基础语法、工作区、大纲、编码、导出、公式、脚注和 Mermaid 等功能示例

### 修复

- 修复段首 `[^数字]:` 转换为脚注定义后光标停留在脚注编号前方、无法继续输入的问题
- 修复脚注定义中的行内格式在保存时被转换为纯文本的问题
- 修复代码示例中的图片文本被误报为缺失图片的问题

## 版本：v1.5.0

更新时间：2026-8-28

### 新增

- 新增独立大纲侧栏，可将大纲分离到窗口右侧并单独调整宽度；分离、合并和窗口尺寸变化带有连续动画
- 视图菜单新增「侧栏设置」子菜单，可切换工作区/大纲、树结构/文档列表，以及启用独立大纲侧栏
- 大纲视图新增右键菜单，支持展开所有章节、收起所有章节和定位当前章节
- 工作区树和文档列表新增内联重命名，可直接编辑名称并保留文件扩展名
- 工作区中新建文件和新建文件夹改为先创建未命名项目，再自动打开或进入重命名状态
- 新增列表缩进命令；光标位于有序、无序或任务列表时，可通过 Tab、Shift+Tab 或菜单调整缩进
- 新增中文与西文、数字之间的可选自动间距，并同步应用于可视化编辑器和导出内容
- 帮助菜单新增「检查更新」，可从 GitHub 获取对应架构的最新安装包并启动更新
- Windows 发布流程改用 Inno Setup，提供 x64 和 ARM64 的含运行时/不含运行时安装包，以及含运行时绿色版 ZIP

### 更改

- 侧边栏展开、收缩和调整宽度时改为实时响应，窗口尺寸与编辑器区域按照当前窗口状态平滑调整
- 独立大纲侧栏固定在窗口右侧，展开时向右扩展窗口，收缩时向左收缩窗口，保持大纲侧栏左上角和宽度稳定
- 侧栏按钮、状态栏模式切换、换行符和缩放控制重新整理；源码/可视化切换改为 `</>` 图标
- 自绘菜单栏改用 `bg-secondary` 作为背景色，首选项与导出窗口顶栏同步使用主题次级背景色
- 所有系统颜色子对话框背景统一改为 `ControlLightLight`
- 编辑菜单新增「全选」命令，快捷键为 Ctrl+A
- 删除工作区中的当前文件后，立即关闭该文件并清空为干净的未命名文档
- 侧栏树结构中当前选中文档使用粗体显示，侧栏右上角按钮改为新建 Markdown 文件
- 工作区新建文件默认在当前工作区根目录或当前文档所在目录创建；无工作区时保持原有新建文档行为
- 清除段落格式命令更名为「清除格式」，并移动到格式菜单底部；图片操作统一收进格式菜单的「图片」子菜单
- 显示代码高亮移动到视图菜单，侧栏视图和外观缩放选项分别收进对应子菜单
- 构建号改为动态读取当前 Git 提交次数，并显示在版本信息和发布产物中

### 修复

- 修复独立大纲侧栏显示为空或未跟随当前文档更新的问题
- 修复侧栏及独立大纲展开/合并动画过程中编辑器文本抽搐、宽度变化异常和边界定位不稳定的问题
- 修复拖动侧栏和大纲分隔条时响应滞后、拖动条与边缘产生间距，以及鼠标纵坐标不同步的问题
- 修复只读模式下选中文本拖动导致可视化编辑器卡死的问题，并清空只读拖拽数据
- 修复可编辑模式下原生拖拽与编辑器选区更新冲突导致的偶发卡死
- 修复拖动图片尺寸手柄时图片尺寸来回切换造成的抽搐
- 修复闭合的 `***粗斜体***` 和脚注引用在可视化输入时无法自动转换的问题
- 修复段首 `[^注释]:` 未正确转换为脚注定义的问题
- 修复列表缩进命令仅在选中文字时可用的问题，使光标停留在列表段落时也能使用
- 修复表格内段落格式命令状态不正确的问题，表格内不再启用不适用的段落结构操作
- 修复大纲点击跳转后的高亮显示，查找替换当前选中文本现在使用更清晰的主题描边
- 修复普通文本文件触发 Markdown 星号标记提示的问题
- 修复启动优化后主窗口、编辑器初始化顺序导致的空引用错误
- 修复更新器无法识别 Inno Setup 安装包的问题，并改为匹配当前架构的不含运行时安装包

## 版本：v1.4.0

更新时间：2026-8-25

### 新增

- 新增 Mermaid 图表支持：可插入语言标注为 `mermaid` 的代码块，在可视化编辑器中渲染为图表，并支持编辑源码、重新渲染、删除以及重新渲染文档中的全部图表
- Mermaid 图表支持 HTML、PDF 与打印导出，空图表和语法错误会显示明确提示，渲染超时不会阻塞编辑器
- 代码块右键菜单新增「声明代码语言」和「复制整段代码」，格式菜单与偏好设置新增「显示代码高亮」开关
- 状态栏编码项改为可点击菜单，支持 UTF-8、UTF-8 BOM、US-ASCII、UTF-16、UTF-16 BOM、GB2312、GBK、GB18030、Big5 与 Shift_JIS
- 切换文件编码时可选择「直接读取」或「转换编码」；直接读取会用目标编码重新解释文件，转换编码会保留当前文本并使用目标编码保存
- 打开文件时新增多编码检测，可识别 BOM、无 BOM UTF-16 以及常见中日文编码，并避免保存时静默丢失无法表示的字符
- 偏好设置「文件」页面新增新建文档默认编码，可与默认换行符一同设置
- 注释定义新增「转到引用」「清空引用」「删除注释」命令，并在找不到引用时显示提示
- 可视化编辑器中的有序列表、无序列表和任务列表支持按 Tab 将当前列表项向后缩进
- 可视化编辑器中的普通段落和标题支持 Tab 插入两个空格、Shift+Tab 移除段首缩进
- 文件菜单与工作区菜单新增纯文本新建文档入口，`.txt` 文档继续使用源码模式编辑

### 更改

- 「插入 Mermaid 图表」不再弹出输入窗口，改为在光标处另起一行插入空的 Mermaid 代码块，用户可直接输入图表源码并渲染
- Mermaid 图表双击后转回可编辑代码块；图表右键菜单根据选中状态提供编辑、重新渲染和删除命令
- Mermaid 图表使用当前排版字体与主题颜色，导出时保持居中，并针对印刷样式移除编辑器背景和边框
- 闭合的 `***粗斜体***`、`**粗体**` 与 `*斜体*` 在可视化输入时会立即转换为对应格式
- 段落格式按钮改为独立浮层定位，输入法组合输入时不再向正文 DOM 插入手柄元素
- 表格中的段落格式按钮改为显示表格右键菜单中的标题、行列、对齐和删除操作，但不显示剪切、复制、粘贴及「复制为」
- 注释定义段落的段落格式按钮改为显示注释专用操作，但不显示剪切、复制、粘贴及「复制为」
- 代码高亮会根据代码块声明的语言显示关键字、字符串、数字、注释、类型和函数等基础语法着色
- 启动流程改为先显示主窗口，再并行初始化 WebView、工作区和启动文档，缩短冷启动时等待窗口出现的时间
- 编辑器面板在 WebView 初始化前即使用当前主题背景，减少启动过程中的白色闪烁
- 编辑器自动隐藏滚动条改为淡入淡出，并在滚动或鼠标靠近右边缘时显示；缩放时保持光标附近内容的视觉位置
- 侧栏新增主题色 `bg-secondary`，所有内置颜色主题均提供介于 `bg-primary` 与 `bg-hover` 之间、且更接近主背景的侧栏底色
- 工作区树选中项背景使用 `bg-selected`，选中并悬停时使用 `bg-selected-hover`，文字和图标保持普通状态颜色
- 侧栏自绘滚动条移除上下箭头，轨道占满控件高度；缩窄容器、增加右侧留白并限制滑块最大高度
- 偏好设置中的文本格式与代码高亮选项重新整理，相关菜单状态、状态栏显示和多语言文案同步更新
- 源码模式支持通过命令插入 Mermaid 代码块，并保持源码与可视化模式之间的图表内容往返

### 修复

- 修复只读模式下选中文本后拖动必然导致可视化编辑器卡死的问题；只读模式现在会阻止正文拖拽并清空拖拽数据
- 修复可编辑模式下拖动文本偶发卡死的问题，减少浏览器原生拖拽与 ProseMirror 选区更新之间的冲突
- 修复拖动图片尺寸手柄时图片宽度在持久化比例与实时尺寸之间反复切换、造成画面抽搐的问题
- 修复闭合的三星号粗斜体在可视化输入时不被识别的问题
- 修复格式刷从右向左选择整行或跨多个段落时未应用格式、仍保持武装状态的问题
- 修复段落格式按钮在表格、列表、代码块、Mermaid 图表和注释定义附近定位或标签不正确的问题
- 修复只读模式下段落格式按钮仍可能显示或响应操作的问题
- 修复注释定义点击跳转不到引用、删除注释后残留引用，以及清空引用时误处理定义文本的问题
- 修复 Mermaid 空内容、错误语法或渲染超时时留下错误 SVG、异常节点或未完成占位内容的问题
- 修复 Mermaid SVG 继承段落缩进和字体样式，导致图表文字错位的问题
- 修复代码块语言、代码内容、Mermaid 选中状态和数量未同步到 Windows 菜单状态的问题
- 修复切换编码后状态栏、BOM 状态和保存编码不同步，以及新建文件未使用偏好设置默认编码的问题
- 修复启动优化后编辑器面板尚未创建时出现空引用错误的问题
- 修复工作区树选中背景使用强调色而不是主题选中背景色的问题
- 修复侧栏滚动条箭头占用轨道空间、滑块左右留白过大，以及内容较少时滑块过长的问题

- 记住上次关闭时文件的只读状态，再次打开该文件时仍以只读模式打开

- 查找/替换由页面内顶栏迁移为原生窗口，弃用前端查找顶栏

- 侧边栏自绘滚动条颜色随主题变化
- 侧边栏文件树行高略微调低、文档列表文字左侧边距增大

## 版本：v1.2.6

更新时间：2026-8-19

### 新增

- 状态栏新增可点击的字数统计入口，可查看字数、去空格字数、汉字字数、西文词数、公式数、代码行数与段落数等统计信息
- 首选项「外观」新增「状态栏」设置，可自定义状态栏中侧栏按钮、字数统计、段落格式、行列位置、编码、换行符、模式切换与缩放比例等项目的显示状态
- 状态栏「执行的命令」新增显示策略，可选择始终显示、短暂显示或不显示；短暂显示会在 5 秒后自动清空
- 可视化模式与源码模式互相切换时新增光标位置跳转与恢复逻辑，尽量保持切换前后的阅读位置一致
- 新增脚注支持，可将 `[^x]` 显示为上标脚注引用，并将 `[^x]:` 段落显示为脚注定义
- 段落菜单新增「插入注释」命令，可填写注释编号和注释文本，并在正文当前位置插入引用、在文末插入定义
- 脚注引用支持按住 Ctrl 后左键点击跳转到对应脚注定义
- 脚注定义段落右键菜单新增「重设注释编号」，可批量替换相同编号的脚注引用和脚注定义

### 更改

- 状态栏最左侧按钮改为仅用于展开或收起侧栏，展开侧栏时显示原图标，收起侧栏时显示新的侧栏收起图标
- 状态栏除最左侧按钮外，文字统一改为 8pt、加粗，并使用当前主题的 `text-secondary` 颜色
- 源码模式取消正文最大宽度限制，使源码编辑区域可随窗口宽度自然展开
- 关于窗口改为单列居中布局，缩小窗口尺寸，使用 92×92 图标，移除确定按钮，并将 GitHub 链接显示为「GitHub 仓库」
- 导出窗口 PDF 标签页图标更新，并调整「柠檬海盐」配色中的图标颜色
- 链接打开方式改为按住 Ctrl 后左键点击，避免编辑时误触打开链接
- 脚注定义段落右键菜单改为专用菜单，仅显示重设编号与基础剪贴板操作，不再显示前端格式菜单、段落格式和格式刷
- 导出 HTML/PDF 时为脚注定义生成专用结构与真实编号元素，使导出结果与可视化渲染保持一致
- 脚注在印刷样式和双色印刷样式下使用对应排版样式文件中的样式覆盖

### 修复

- 修复源码模式状态栏行数、列数始终显示为第 1 行、第 1 列的问题
- 修复可视化模式与源码模式切换时，空行、引用空行、代码块标记、表格和分割线等内容导致跳转行数不准确的问题
- 修复表格附近从可视化模式切换到源码模式时跳转过远的问题
- 修复状态栏隐藏「执行的命令」后，其它状态栏信息错误靠左显示的问题
- 修复源码模式下字数统计、行列位置与文档统计信息未同步更新的问题
- 修复插入脚注定义时上方多插入一个空行的问题
- 修复手动输入脚注定义后被吞掉、丢失或保存为字面量的问题
- 修复脚注跳转时仅移动光标和高亮、视图滚动不到位的问题
- 修复点击不存在定义的脚注引用时没有明确提示的问题
- 修复导出时脚注定义被按普通段落处理、暴露 Markdown 标记或缺少脚注编号的问题

## 版本：v1.2.5

更新时间：2026-8-19

### 新增

- 源码模式支持撤销、重做，并统一以纯文本方式处理粘贴内容
- 右键菜单与顶部菜单中的“复制为”改为“复制/粘贴为”，新增“粘贴为纯文本”命令，快捷键为 Ctrl+Shift+V
