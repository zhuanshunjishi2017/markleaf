# MarkLeaf 更新内容

## 版本：v1.3.1

更新时间：2026-8-21

### 新增

- 状态栏换行符改为带勾选状态的菜单，可为当前已打开文件切换 LF/CRLF 并在保存时写入；偏好设置「文本格式」可设置新建文件默认换行符
- 状态栏「可视化」改为带勾选状态的模式菜单，可明确选择可视化或源码模式
- 状态栏与偏好设置支持选择 UTF-8、UTF-8 with BOM、US-ASCII、UTF-16、UTF-16 with BOM、GB2312、GBK、GB18030、Big5 和 Shift_JIS
- 打开文件时自动识别 UTF-8/UTF-16 BOM；切换编码可能导致乱码时显示警告，并在保存时避免不可表示字符被静默丢失
- 打开无 BOM 文件时会根据可逆性和乱码特征，对 UTF-8、UTF-16 以及中日文编码候选进行评分并自动选择更合适的编码

### 更改

- 偏好设置窗口改为更紧凑的居中布局，重新调整底部操作区间距、说明文案缩进以及「文件」页面的视觉重心
- 从隐藏侧边栏状态启动后的首次展开动画与后续展开/收起动画统一，并从真实的零宽状态开始
- 移除重复的「UTF-8 without BOM」和「UTF-16 without BOM」选项；无 BOM 编码分别统一显示为「UTF-8」和「UTF-16」

### 修复

- 修复未选择文本时「拷贝」与「复制为」仍可用的问题，编辑和只读模式现在都会正确置灰
- 修复查找与替换文本框无法使用 ⌘V 等系统剪贴板快捷键，以及右键菜单在第二次打开后变窄、折叠选项的问题
- 修复工作区中单击文件后选中高亮只闪现一下、必须双击才会保持的问题
- 修复已打开工作区后通过侧栏按钮选择另一个文件夹时应用崩溃的问题
- 修复隐藏侧边栏启动后首次显示时，「暂未打开工作区」错位、打开文件夹按钮消失及侧栏宽度异常的问题
- 修复首次显示侧边栏的动画起始宽度和节奏与正常展开动画不一致的问题
- 修复侧边栏隐藏时，打开文件或执行保存会意外重新显示侧边栏的问题
- 兼容旧版本保存的 UTF-8/UTF-16 无 BOM 设置，升级后自动迁移到新的选项名称

## 版本：v1.3.0

更新时间：2026-8-20

### 新增

- 搜索结果显示文件夹图标与关键词附近的上下文；点击结果后会退出搜索并在工作区树中展开、选中目标文件
- 状态栏支持自定义：侧栏切换按钮、命令状态、字符数、块类型、光标位置、编码、换行符、源码/可视化切换与缩放比例均可独立显示或隐藏
- 状态栏字符数可点击，打开详细文档统计（字数、已选字符数、总字符数、非空白字符数、CJK 字符数、西文单词数、公式数、代码行数、段落数与行列位置）
- 工作区右键菜单补齐新建文件、新建文件夹、复制路径、在 Finder 中显示、在新窗口打开、重命名、删除、树/列表切换、排序、刷新与关闭工作区
- 文档列表模式显示所在文件夹与修改时间，支持按文件名或修改时间排序，并可切换升序/降序
- 支持从 Finder 拖入 .md/.txt/.markdown 文件到工作区，自动复制到目标目录
- 工作区树支持按 Return 打开文件，或在文件夹上展开/收起
- 图片右键菜单与格式菜单补齐更换图片、调整大小（100%/75%/90%/50%）、顺时针旋转与图片另存为
- 文件菜单新增「以只读方式打开」
- 段落菜单新增「清除段落格式」
- 偏好设置「外观」新增「自动隐藏滚动条」开关

### 更改

- 首次启动不再自动接管 Markdown/纯文本文件关联；只有用户主动启用后，MarkLeaf 才会成为默认编辑器
- 状态栏命令反馈与文档状态拆分为独立字段，不再互相覆盖；「临时显示」模式会在 5 秒后自动清空
- 自定义状态栏窗口改为紧凑布局，标题、选项与命令状态显示方式使用统一对齐和间距
- PDF 与 HTML 共用一个「导出…」窗口；文件菜单只保留一个导出入口，同时继续提供「按上次设置导出」
- 导出窗口默认使用当前排版样式和配色主题，默认页边距改为「标准」；仍可为单次导出选择其他配色，按上次设置导出时保留历史配色
- 搜索支持真正取消，停止继续遍历目录和读取文件

### 修复

- 修复点击搜索结果后偶尔无法在工作区树中定位目标文件的问题
- 修复工作区右键菜单缺少新建、重命名、删除、排序等操作的问题
- 修复从 Finder 拖入文件到工作区被拒绝的问题
- 修复文档列表信息不足且无法排序的问题
- 修复取消搜索后仍继续读取文件、占用磁盘与 CPU 的问题
- 修复状态栏缺少编码、换行符、源码/可视化切换、缩放等字段且无法自定义的问题
- 修复自定义状态栏窗口左侧留白过大、标题未对齐以及下拉框距离过远的问题
- 修复文件菜单重复显示旧「导出为」子菜单的问题
- 修复导出窗口忽略当前主题、默认使用历史深色配色，以及默认页边距显示为「自定义」的问题
- 修复只读模式下 ⌘A 全选、⌘C 复制快捷键无效，以及选区无法用 Esc 或失焦取消、高亮残留的问题

### Windows 端新增

- 新增可自定义快捷键体系：快捷键设置窗口支持录制新快捷键、清除、恢复默认、全部恢复默认，可自定义大部分菜单命令的快捷键
- 菜单栏命令右侧动态显示当前生效的快捷键，跟随自定义设置实时更新
- 新增原生「查找/替换」窗口，支持查找下一个/上一个、替换、全部替换、区分大小写、全词匹配，替代原页面内查找栏
- 侧边栏顶部新增「打开文件夹」按钮，仅在工作区标签下显示，点击弹出文件夹选择器
- 侧边栏搜索框新增清除按钮，输入内容后显示，点击清空并退出搜索
- 侧边栏空状态新增「暂未打开工作区」提示文字，未打开工作区时搜索框自动禁用
- 链接与脚注角标支持悬停提示：鼠标变为手形，显示链接地址或脚注定义，以及「按住 Ctrl 并单击」的操作提示
- 段落格式按钮按下后高亮整个段落，光标移出该段落后自动取消高亮
- 视图菜单与工作区右键菜单的「树结构 / 文档列表」命令新增勾选状态，标识当前视图
- 记住上次关闭时文件的只读状态，再次打开该文件时仍以只读模式打开

### Windows 端更改

- 侧边栏顶部按钮由「收起/展开侧栏」改为「打开文件夹」，与 macOS 端保持一致（收起侧栏入口保留在状态栏最左侧按钮）
- 补齐下划线、提升标题级别、降低标题级别的默认快捷键（Ctrl+U、Ctrl+.、Ctrl+,），并纳入可自定义范围
- 查找/替换由页面内顶栏迁移为原生窗口，弃用前端查找顶栏
- 点击滚动条轨道时，滑块中心移动到点击处并将内容滚动到该位置
- 侧边栏自绘滚动条颜色随主题变化
- 侧边栏文件树行高略微调低、文档列表文字左侧边距增大
- 颜色主题「薰衣草」更名为「紫罗兰」、「玫瑰」更名为「蔷薇色」
- 「柠檬海盐」主题滚动条颜色微调
- 导出窗口控件尺寸微调

### Windows 端修复

- 修复侧边栏滚动条颜色不随主题变化的问题

## 版本：v1.2.6

更新时间：2026-8-19

### 新增

- 状态栏新增可点击的字数统计入口，可查看字数、去空格字数、汉字字数、西文词数、公式数、代码行数与段落数等统计信息
- 首选项「外观」新增「状态栏」设置，可自定义状态栏中侧栏按钮、字数统计、段落格式、行列位置、编码、换行符、模式切换与缩放比例等项目的显示状态
- 状态栏「执行的命令」新增显示策略，可选择始终显示、短暂显示或不显示；短暂显示会在 5 秒后自动清空
- 可视化模式与源码模式互相切换时新增光标位置跳转与恢复逻辑，尽量保持切换前后的阅读位置一致
- 新增脚注支持，可将 `[^x]` 显示为上标脚注引用，并将 `[^x]:` 段落显示为脚注定义
- 段落菜单新增「插入注释」命令，可填写注释编号和注释文本，并在正文当前位置插入引用、在文末插入定义
- 脚注引用支持按住 Ctrl 后左键点击跳转到对应脚注定义
- 脚注定义段落右键菜单新增「重设注释编号」，可批量替换相同编号的脚注引用和脚注定义

### 更改

- 状态栏最左侧按钮改为仅用于展开或收起侧栏，展开侧栏时显示原图标，收起侧栏时显示新的侧栏收起图标
- 状态栏除最左侧按钮外，文字统一改为 8pt、加粗，并使用当前主题的 `text-secondary` 颜色
- 源码模式取消正文最大宽度限制，使源码编辑区域可随窗口宽度自然展开
- 关于窗口改为单列居中布局，缩小窗口尺寸，使用 92×92 图标，移除确定按钮，并将 GitHub 链接显示为「GitHub 仓库」
- 导出窗口 PDF 标签页图标更新，并调整「柠檬海盐」配色中的图标颜色
- 链接打开方式改为按住 Ctrl 后左键点击，避免编辑时误触打开链接
- 脚注定义段落右键菜单改为专用菜单，仅显示重设编号与基础剪贴板操作，不再显示前端格式菜单、段落格式和格式刷
- 导出 HTML/PDF 时为脚注定义生成专用结构与真实编号元素，使导出结果与可视化渲染保持一致
- 脚注在印刷样式和双色印刷样式下使用对应排版样式文件中的样式覆盖

### 修复

- 修复源码模式状态栏行数、列数始终显示为第 1 行、第 1 列的问题
- 修复可视化模式与源码模式切换时，空行、引用空行、代码块标记、表格和分割线等内容导致跳转行数不准确的问题
- 修复表格附近从可视化模式切换到源码模式时跳转过远的问题
- 修复状态栏隐藏「执行的命令」后，其它状态栏信息错误靠左显示的问题
- 修复源码模式下字数统计、行列位置与文档统计信息未同步更新的问题
- 修复插入脚注定义时上方多插入一个空行的问题
- 修复手动输入脚注定义后被吞掉、丢失或保存为字面量的问题
- 修复脚注跳转时仅移动光标和高亮、视图滚动不到位的问题
- 修复点击不存在定义的脚注引用时没有明确提示的问题
- 修复导出时脚注定义被按普通段落处理、暴露 Markdown 标记或缺少脚注编号的问题

## 版本：v1.2.5

更新时间：2026-8-19

### 新增

- 源码模式支持撤销、重做，并统一以纯文本方式处理粘贴内容
- 右键菜单与顶部菜单中的“复制为”改为“复制/粘贴为”，新增“粘贴为纯文本”命令，快捷键为 Ctrl+Shift+V
- 源码模式支持检测不符合 CommonMark 规则的闭合星号标记，并可选择保留字面量或转为 HTML 标签；提示窗口支持“不再提示”和“了解详情”
- Markdown 生成时自动检测加粗、斜体标记的危险边界，必要时转为 HTML 标签，避免重新加载后暴露星号源码
- 只读模式使用受限的系统右键菜单，并禁用源码模式编辑操作
- 合并 HTML 导出窗口与 PDF 导出窗口，使用统一导出窗口，并通过左侧标签页切换导出格式
- 导出菜单新增“按上次的设置导出”，可复用上次的导出格式、页边距、颜色模式、排版样式、页眉页脚等设置
- PDF 导出新增页眉页脚设置，支持文档标题、页码、总页数等预设，并支持自定义页眉页脚
- 新增导出设置持久化，下次打开导出窗口时可记住上次相关配置
- 新增一个浅色配色方案：“柠檬海盐”

### 更改

- 基础排版自适应边距删除最小一档，并适当减小左右边距
- 导出窗口打开时，颜色方案和排版样式默认同步为当前正在应用的设置
- PDF 页眉页脚字体改为从所选排版样式的 CSS 文件中读取，字号统一为正文标准字号的 0.875
- PDF 页眉页脚上下边距调整为 6mm，并微调页眉页脚位置
- PDF 页眉页脚下拉框、自定义页眉页脚按钮、自定义边距按钮的尺寸与周边控件保持一致
- 自定义边距按钮改为始终可用，用户手动修改页边距后自动切换为自定义边距
- 导出窗口左侧面板、设置面板与标签页面板右侧增加分割线，颜色与标签页底部分割线保持一致
- PDF 导出时移除正文容器的最大宽度限制，使表格可扩展到页边距范围内
- 同步更新相关命令、快捷键、菜单状态、编辑器协议、设置项和多语言文案

### 修复

- 修复源码模式粘贴 HTML 或富文本时内容为空的问题
- 修复源码模式粘贴纯文本后光标位置异常后移的问题
- 修复可视化模式输入全角符号、全角字母、全角数字时光标异常跳动的问题
- 修复可视化编辑器中复制图片后再次粘贴会变为空白或仅保留图片标题文本的问题
- 修复首选项窗口勾选“跟随系统颜色模式”后点击确定不会立即应用主题的问题
- 修复只读模式下仍可能弹出前端编辑菜单或响应编辑操作的问题
- 修复 PDF 页眉页脚未按当前排版样式字体渲染的问题
- 修复 PDF 导出中表格无法占满页边距范围内可用宽度的问题

## 版本：v1.2.4

更新时间：2026-8-17

### 新增

- 支持表格标题与图片标题：表格标题以 `> tablecaption:` 前缀标注，显示在表格上方；图片标题存入图片元数据，显示在图片下方，均居中显示

- 修复表格/图片标题在编辑器与导出中颜色、字号不一致的问题（统一为主文字色、标准字号的 15/16）
