# 欢迎来到 MarkLeaf!

这是一个非常简洁但功能丰富的 Markdown 文本编辑器，据说 fcz 最初开发 MarkLeaf 只是想为了让 Markdown 文本排版像书页一样，所以取了这样的名字。

初次见面，希望这份文档将带你快速熟悉MarkLeaf。你可以试着修改其中的内容，试试不同的格式和功能。

## MarkLeaf 可以做什么呢？

MarkLeaf 是主要使用 Markdown 来进行写作与排版的文本编辑器。Markdown 使用简单的标记表示文档结构。在可视化模式中，你可以通过菜单和段落格式按钮完成这些操作。常用的操作都有熟悉的键盘快捷键与其对应，尝试利用快捷键可以让这些功能更加得心应手。

### 标题

在可视化模式下，你可以通过菜单项或段落格式按钮设置标题，也可以输入 `#` 后按下空格，这会将这一段自动转化为标题。

在源码模式下，在文字前添加 `#` 可以创建标题。`#` 的数量表示标题级别，如：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

标题会自动出现在大纲中。单击大纲项目即可跳转到对应章节。

### 行内格式

- `**粗体**` 显示为 **粗体**
- `*斜体*` 显示为 *斜体*
- `***粗斜体***` 显示为 ***粗斜体***
- `~~删除线~~` 显示为 ~~删除线~~
- `++下划线++` 显示为 ++下划线++
- `==高亮==`  显示为 ==高亮==

选中文字后，可以使用“格式”菜单或上下文菜单应用这些样式。当然，你也可以在编辑器中输入闭合的这些标记符号，被包裹的文字也会自动变成相应的格式。

### 列表

Markdown 为你提供了三种不同的列表：

#### 无序列表

这是用 `-` 作前缀的列表：

- 记录一个想法
- 整理相关资料
- 完成第一版

#### 有序列表

这是用 `1.` 作前缀的列表：

1. 编写内容
2. 检查格式
3. 保存并导出

#### 任务列表

这是用 `[ ]` 作前缀的列表, `[x]`  代表任务已完成：

- [x] 安装并打开 MarkLeaf
- [ ] 创建第一篇文档
- [ ] 尝试导出为 HTML 或 PDF

当光标位于列表项中时，可以按 `Tab` 增加缩进，让它成为一个列表的子项目，或者按 `Shift+Tab` 减少缩进。

### 行内公式

使用一对闭合的美元符号包围 LaTeX 内容即可插入行内公式。例如，`$E=mc^2$` 会渲染为：$E=mc^2$。

### 段间公式

较长的公式可以单独成段，它们是用一边两个美元符号包裹起来的。

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

你可以通过菜单插入公式，也可以直接输入公式的 LaTeX 源码，右键公式还可以让公式在段间公式和行内公式中切换哦。

### 脚注

在正文中输入闭合的脚注引用，例如 `[^1]`，MarkLeaf 会将它显示为上标。将脚注定义放在段首：

这是一段带有补充说明的文字[^1]。

[^1]: 脚注可以包含 粗体、斜体、`行内代码` ，也支持行内公式  $x^2+y^2$ 。将鼠标悬停在正文中的脚注编号上，可以查看其预览。

按住 `Ctrl` 并单击脚注引用，可以跳转到对应的脚注定义，在脚注定义上按住 `Ctrl` 并单击，即可回到引用。

### Mermaid 图表

MarkLeaf 可以把语言标注为 `mermaid` 的代码块渲染为支持的图表：

```mermaid
flowchart LR
    A[开始写作] --> B[整理结构]
    B --> C[检查内容]
    C --> D[保存或导出]
```

你可以通过菜单插入空的 Mermaid 图表，输入源码后将其渲染，也可以重新编辑和刷新图表。

## 轻松使用 MarkLeaf

### 排版样式与颜色主题

使用“查看 &gt; 排版样式”可以更改渲染出的Markdown文本的排版。每一种样式都有着独特的风格，例如：

- 印刷品样式能够带来纸质书的观感；
- LaTeX样式让你的文本像是用LaTeX渲染的一样。

此外，我们提供了数十种预设的配色方案，包含深色和浅色主题，挑选一个你喜欢的试试吧！

其实所有的主题其实都是CSS文件哦！这意味着你可以自己创建属于你的排版样式和颜色主题，所有符合格式的主题放在主题文件夹内都会被识别哦！

### 使用段落格式按钮

把光标悬停在某个段落，你会看到左上方有一个小小的矩形按钮，单击这个按钮会有很多关于段落与格式的快捷操作。使用它来快速的调整段落的格式吧！

### 极简模式

按下 `F11`，即可切换到极简模式，这个模式下只有文章本身而没有任何其他的干扰，你可以将思绪集中在写作本身。需要退出时，再次按下`F11`或者按下`Esc`即可。

### 专注模式与打字机模式

按下 `F8` 可进入专注模式，专注模式下，除当前段落外的段落皆会隐去，帮助你专注于当前的内容。 `F9` 的打字机模式则可以保持光标始终处在屏幕中央。

### 使用侧栏

打开文件夹后，工作区会列出其中的 Markdown 和纯文本文档。你可以：

- 新建文件或文件夹
- 双击打开文档
- 在文件名位置直接重命名
- 使用树结构查看目录，或切换到文档列表
- 使用大纲浏览当前文档的标题
- 将大纲分离到窗口右侧，独立调整宽度

侧栏是否显示以及窗口大小会自动保存，下次启动时可以恢复到上次使用的状态。你也可以将大纲与工作区分离。

### 保存、编码与导出

状态栏会显示当前文件的编码、换行符和缩放比例。单击这些项目可以打开对应菜单。

切换文件编码时：

- “直接读取”会使用所选编码重新解释文件内容。
- “转换编码”会保留当前文字内容，并使用所选编码保存。

如果不确定，应优先选择“转换编码”，并在转换前保存重要内容。

通过“文件 &gt; 导出”可以将文档导出为适合浏览、分享或打印的格式。导出内容会保留表格、公式、脚注和 Mermaid 图表等受支持的内容。**试试用“印刷品”或“LaTeX”导出文档，它们会让你的文档更适合于打印与阅读！**
