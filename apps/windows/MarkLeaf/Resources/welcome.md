# 欢迎来到MarkLeaf!

这是一个非常简洁但功能丰富的 Markdown 文本编辑器，据说fcz最初开发MarkLeaf只是想为了让Markdown文本排版像书页一样，所以取了这样的名字。

这份文档将带你快速熟悉MarkLeaf。你可以试着修改其中的内容，试试不同的格式和功能。

## 初次见面

1. 选择“文件 &gt; 新建 Markdown 文档”开始写作，或打开已有的 `.md` 文件。
2. 使用窗口底部的 `</>` 按钮，在可视化模式和源码模式之间切换。
3. 使用“文件 &gt; 保存”保存文档；第一次保存新文档时，需要选择文件名和位置。
4. 打开一个文件夹作为工作区后，可以在左侧侧栏中浏览、新建、重命名和管理文档。

> tablecaption: MarkLeaf的常用快捷键


| 操作   | 快捷键      |
| ---- | -------- |
| 新建文档 | `Ctrl+N` |
| 打开文档 | `Ctrl+O` |
| 保存文档 | `Ctrl+S` |
| 查找   | `Ctrl+F` |
| 全选   | `Ctrl+A` |
| 撤销   | `Ctrl+Z` |
| 重做   | `Ctrl+Y` |


## Markdown 基础

Markdown 使用简单的标记表示文档结构。在可视化模式中，你也可以通过菜单和段落格式按钮完成这些操作。

### 标题

在源码模式中，在文字前添加 `#` 可以创建标题。`#` 的数量表示标题级别：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

标题会自动出现在大纲中。单击大纲项目即可跳转到对应章节。

### 行内格式

- `**粗体**` 显示为 **粗体**
- `*斜体*` 显示为 *斜体*
- `***粗斜体***` 显示为 ***粗斜体***
- `~~删除线~~` 显示为 ~~删除线~~
- `行内代码` 显示为 `行内代码`

选中文字后，可以使用“格式”菜单或编辑器中的格式按钮应用这些样式。

### 列表

Markdown为你提供了三种不同的列表：

无序列表：

- 记录一个想法
- 整理相关资料
- 完成第一版

有序列表：

1. 编写内容
2. 检查格式
3. 保存并导出

任务列表：

- [x] 安装并打开 MarkLeaf
- [ ] 创建第一篇文档
- [ ] 尝试导出为 HTML 或 PDF

当光标位于列表项中时，可以按 `Tab` 增加缩进，让它成为一个列表的子项目，或者按 `Shift+Tab` 减少缩进。

### 引用与代码块

> 写作不是把所有内容一次写对，而是让想法逐渐变得清晰。

使用三个反引号可以创建代码块，并在开头声明语言：

```python
message = 'Hello, MarkLeaf!'
print(message)
```

## MarkLeaf可以做什么呢？

### 表格

你可以创建一个表格，然后编辑其中的内容，就像下面这样。


| 功能    | 用途                      |
| ----- | ----------------------- |
| 可视化编辑 | 专注内容，不必时刻处理 Markdown 标记 |
| 源码编辑  | 精确控制 Markdown 文本        |
| 工作区   | 管理同一文件夹中的多篇文档           |
| 大纲    | 浏览标题结构并快速跳转             |
| 导出    | 生成便于分享和打印的内容            |


将光标放在表格中，可以通过表格菜单增加或删除行列、调整对齐方式，不同于其他编辑器，在这里，你可以为表格**设置标题**，右键菜单试试吧！

### 行内公式

使用一对美元符号包围 LaTeX 内容即可插入行内公式。例如，`$E=mc^2$` 会渲染为：$E=mc^2$。

再比如勾股定理：$a^2+b^2=c^2$。

### 段间公式

较长的公式可以单独成段：

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

你可以通过菜单插入公式，也可以直接输入 Markdown 公式语法。

### 脚注

在正文中输入闭合的脚注引用，例如 `[^1]`，MarkLeaf 会将它显示为上标。将脚注定义放在段首：

这是一段带有补充说明的文字[^1]。

[^1]: 脚注可以包含 粗体、斜体、行内代码，也支持行内公式 x^2+y^2。将鼠标悬停在正文中的脚注编号上，可以查看其预览。

按住 `Ctrl` 并单击脚注引用，可以跳转到对应的脚注定义，在脚注定义上按住 `Ctrl` 并单击，即可回到引用。

### Mermaid 图表

MarkLeaf 可以把语言标注为 `mermaid` 的代码块渲染为图表：

```mermaid
flowchart LR
    A[开始写作] --> B[整理结构]
    B --> C[检查内容]
    C --> D[保存或导出]
```

你可以通过菜单插入空的 Mermaid 图表，输入源码后将其渲染，也可以重新编辑和刷新图表。

### 图片与链接

Markdown 链接和图片的写法如下，不过你可以直接通过“格式菜单插入，不必直接编写源码：

```markdown
[链接文字](https://example.com)
![图片说明](D:/Project/markleaf/apps/windows/MarkLeaf/Resources/example.jpg)
```

![内联图片](https://placehold.co/600x400/EEE/333?text=Example+Image "图片标题 || markleaf:widthPct=75;ratio=0.6667;rotation=0")

插入的图片就会像这样表示在文档中，你可以旋转、调整大小，也可以为其添加标题。

### 排版样式与颜色主题

使用“查看 &gt; 排版样式”可以更改渲染出的Markdown文本的排版。每一种样式都风格显著。

- 印刷品样式能够带来纸质书的观感；
- LaTeX样式让你的文本像是用LaTeX渲染的一样。

此外，应用提供了数十种预设的配色方案，包含深色和浅色主题，挑选一个你喜欢的试试吧！

还有，所有的主题其实都是CSS文件哦！这意味着你可以自己创建属于你的排版样式和颜色主题，所有符合格式的主题放在主题文件夹内都会被识别哦！

### 使用段落格式按钮

把光标悬停在某个段落，你会看到左上方有一个小小的矩形按钮，单击这个按钮会有很多关于段落与格式的快捷操作。使用它来快速的调整段落的格式吧！

### 专注模式

按下 `F11`，即可切换到专注模式，这个模式下只有文章本身而没有任何其他的干扰，你可以专心的进行写作。需要退出时，再次按下`F11`或者按下`Esc`即可

### 使用侧栏

打开文件夹后，工作区会列出其中的 Markdown 和纯文本文档。你可以：

- 新建文件或文件夹
- 双击打开文档
- 在文件名位置直接重命名
- 使用树结构查看目录，或切换到文档列表
- 使用大纲浏览当前文档的标题
- 将大纲分离到窗口右侧，独立调整宽度

侧栏是否显示以及窗口大小会自动保存，下次启动时可以恢复到上次使用的状态。

### 保存、编码与导出

状态栏会显示当前文件的编码、换行符和缩放比例。单击这些项目可以打开对应菜单。

切换文件编码时：

- “直接读取”会使用所选编码重新解释文件内容。
- “转换编码”会保留当前文字内容，并使用所选编码保存。

如果不确定，应优先选择“转换编码”，并在转换前保存重要内容。

通过“文件 &gt; 导出”可以将文档导出为适合浏览、分享或打印的格式。导出内容会保留表格、公式、脚注和 Mermaid 图表等受支持的内容。
