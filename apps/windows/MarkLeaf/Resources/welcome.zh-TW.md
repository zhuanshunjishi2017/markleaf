# 歡迎來到 MarkLeaf！

這是一款非常簡潔但功能豐富的 Markdown 文字編輯器。據說 fcz 最初開發 MarkLeaf，只是希望讓 Markdown 文字排版像書頁一樣，因此取了這個名字。

初次見面，希望這份文件能帶你快速熟悉 MarkLeaf。你可以試著修改其中的內容，試試不同的格式與功能。

## MarkLeaf 可以做什麼？

MarkLeaf 是主要使用 Markdown 進行寫作與排版的文字編輯器。Markdown 使用簡單的標記表示文件結構。在可視化模式中，你可以透過選單與段落格式按鈕完成這些操作。常用操作都有熟悉的鍵盤快速鍵，善用快速鍵可以讓這些功能更加得心應手。

### 標題

在可視化模式中，你可以透過選單或段落格式按鈕設定標題，也可以輸入 `#` 後按下空格，這會將這一段自動轉換為標題。

在原始碼模式中，於文字前加入 `#` 可以建立標題。`#` 的數量表示標題層級，例如：

```markdown
# 一級標題
## 二級標題
### 三級標題
```

標題會自動出現在大綱中。點擊大綱項目即可跳轉到對應章節。

### 行內格式

- `**粗體**` 顯示為 **粗體**
- `*斜體*` 顯示為 *斜體*
- `***粗斜體***` 顯示為 ***粗斜體***
- `~~刪除線~~` 顯示為 ~~刪除線~~
- `++底線++` 顯示為 ++底線++
- `==螢光標記==` 顯示為 ==螢光標記==

選取文字後，可以使用「格式」選單或右鍵選單套用這些樣式。當然，你也可以在編輯器中輸入成對的標記符號，被包住的文字也會自動變成相應的格式。

### 清單

Markdown 為你提供三種不同的清單：

#### 無序清單

這是使用 `-` 作為前綴的清單：

- 記錄一個想法
- 整理相關資料
- 完成第一版

#### 有序清單

這是使用 `1.` 作為前綴的清單：

1. 撰寫內容
2. 檢查格式
3. 儲存並匯出

#### 任務清單

這是使用 `[ ]` 作為前綴的清單，`[x]` 代表任務已完成：

- [x] 安裝並開啟 MarkLeaf
- [ ] 建立第一份文件
- [ ] 試試匯出為 HTML 或 PDF

當游標位於清單項目中時，可以按 `Tab` 增加縮排，使其成為清單的子項目，或按 `Shift+Tab` 減少縮排。

### 引用與程式碼區塊

使用 `>` 可以建立引用區塊，`>` 的數量代表引用層級。引用區塊中的文字就像下面這樣。現在另起一行，輸入大於號，再按下空格，看看格式有什麼變化！

> 那彷彿催人落淚的殷紅夕陽，將我心中的你消融而去。

使用三個反引號可以建立程式碼區塊，並在開頭宣告語言：

```python
message = 'Hello, MarkLeaf!'
print(message)
```

### 表格

你可以從選單中，或按下 `Ctrl+T` 建立表格，然後編輯其中的內容，就像下面這樣。

### 行內公式

使用一對閉合的美元符號包圍 LaTeX 內容即可插入行內公式。例如，`$E=mc^2$` 會渲染為：$E=mc^2$。

再例如勾股定理：$a^2+b^2=c^2$。

> 現在試著在這個公式的左右各輸入一個美元符號，看看它會變成什麼呢！
>
> \\int\_a^b f(x) \\, dx = F(b) - F(a) = F(x) \\Big|\_a^b

### 段間公式

較長的公式可以獨立成段，它們是在左右各使用兩個美元符號包裹的。

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

你可以透過選單插入公式，也可以直接輸入公式的 LaTeX 原始碼；右鍵點擊公式，還可以在段間公式與行內公式之間切換。

### 註腳

在正文中輸入閉合的註腳引用，例如 `[^1]`，MarkLeaf 會將它顯示為上標。將註腳定義放在段首：

這是一段帶有補充說明的文字[^1]。

[^1]: 註腳可以包含粗體、斜體、`行內程式碼`，也支援行內公式 $x^2+y^2$。將滑鼠懸停在正文中的註腳編號上，可以查看其預覽。

按住 `Ctrl` 並點擊註腳引用，可以跳轉到對應的註腳定義；在註腳定義上按住 `Ctrl` 並點擊，即可回到引用。

### Mermaid 圖表

MarkLeaf 可以將語言標註為 `mermaid` 的程式碼區塊渲染為支援的圖表：

```mermaid
flowchart LR
    A[開始寫作] --> B[整理結構]
    B --> C[檢查內容]
    C --> D[儲存或匯出]
```

你可以透過選單插入空的 Mermaid 圖表，輸入原始碼後將其渲染，也可以重新編輯與重新整理圖表。

### 圖片與連結

## 輕鬆使用 MarkLeaf

### 排版樣式與配色主題

使用「查看 > 排版樣式」可以變更渲染後 Markdown 文字的排版。每一種樣式都有獨特的風格，例如：

- 印刷品樣式能帶來紙本書的觀感；
- LaTeX 樣式讓你的文字像是使用 LaTeX 渲染的一樣。

此外，我們提供了數十種預設配色方案，包含深色與淺色主題，挑一個你喜歡的試試吧！

其實所有主題都是 CSS 檔案！這表示你可以自行建立屬於自己的排版樣式與配色主題，所有符合格式並放在主題資料夾中的主題都會被識別。

### 使用段落格式按鈕

將游標懸停在某個段落上，你會看到左上方有一個小小的矩形按鈕。點擊這個按鈕會出現許多段落與格式的快速操作，使用它來快速調整段落格式吧！

### 最簡模式

按下 `F11` 即可切換到最簡模式，這個模式下只有文章本身而沒有任何其他干擾，你可以將思緒集中在寫作本身。需要退出時，再次按下 `F11` 或按下 `Esc` 即可。

### 專注模式與打字機模式

按下 `F8` 可進入專注模式，專注模式下，除目前段落外的段落皆會變淡，幫助你專注於目前的內容。`F9` 的打字機模式則可以保持游標始終處在螢幕中央。

### 使用側欄

開啟資料夾後，工作區會列出其中的 Markdown 和純文字文件。你可以：

- 建立檔案或資料夾
- 雙擊開啟文件
- 在檔名區域直接重新命名
- 使用樹狀結構查看目錄，或切換到文件清單
- 使用大綱瀏覽目前文件的標題
- 將大綱分離到視窗右側，獨立調整寬度

側欄是否顯示以及視窗大小都會自動儲存，下次啟動時可以恢復上次使用的狀態。你也可以將大綱與工作區分離。

### 儲存、編碼與匯出

狀態列會顯示目前檔案的編碼、換行符號與縮放比例。點擊這些項目即可開啟對應選單。

切換檔案編碼時：

- 「直接讀取」會使用選定的編碼重新解讀檔案內容。
- 「轉換編碼」會保留目前文字內容，並使用選定的編碼儲存。

如果不確定，建議優先選擇「轉換編碼」，並在轉換前儲存重要內容。

透過「檔案 > 匯出」可以將文件匯出為適合瀏覽、分享或列印的格式。匯出內容會保留表格、公式、註腳與 Mermaid 圖表等支援的內容。**試試使用「印刷品」或「LaTeX」匯出文件，它們會讓文件更適合列印與閱讀！**
