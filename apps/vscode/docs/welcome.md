# MarkLeaf for VS Code

MarkLeaf 0.3.1 需要 VS Code 1.120 或更高版本。打开 Markdown 文件即可阅读和编辑，包括 `.markdown`、`.mdown` 和 `.mkd` 等常用扩展名。若已指定其他默认编辑器，可从 **Reopen Editor With…** 选择 MarkLeaf。

## 打开文档与查看差异

- 在资源管理器使用 **MarkLeaf: 打开文档**。JSON、源码、日志和无扩展名文本使用 VS Code 原生文本编辑器。
- 按 **Ctrl+Shift+V**（macOS 为 **Cmd+Shift+V**）切换 Markdown 渲染与源码。Git 工作区、暂存区和提交历史的比较默认显示原生文本差异，两侧保留各自的版本。
- 底部的“源码”打开当前文件的文本编辑器。编码、换行符按钮使用 VS Code 原有操作，缩放按钮只调整阅读视图。底部显示“已同步到 VS Code”时，文件是否已写入磁盘可查看标签页的未保存标记。

## 编辑与导出

- **格式**提供格式刷和表格列宽操作。可拖动列边界，也可按内容调整、平均分配或重置列宽。“全部格式操作…”包含标题、列表、脚注及其他 Markdown 操作。
- **编辑**提供图片插入与编辑、复制为 Markdown／纯文本／HTML、查找和替换。图片还可通过粘贴或拖放插入。
- 选中公式或 Mermaid 图表，再次点击即可编辑源码。选中已渲染的图表后，可在**导出**菜单将该图单独保存为 SVG 或 2× PNG。
- **导出**也支持整篇文档的 PDF、独立 HTML、PNG/JPG 长图、预览和打印。PDF、整页图片、预览和打印使用本机已安装的 Chrome 或 Edge。

## 阅读与设置

**视图**提供大纲、专注段落、打字机滚动和自定义快捷键。大纲可搜索和折叠标题。阅读模式可复制、查找与导航，点击工具栏的模式按钮可恢复编辑。

从 **视图 → 排版与设置… → 全部 MarkLeaf 设置…** 或扩展详情页进入设置。可调整字号与行宽，通过 `markleaf.adaptiveJustification` 启用自适应两端对齐，或用 `markleaf.shortcuts` 设置格式快捷键。默认安装包的扩展 ID 为 `markleaf.markleaf`。
