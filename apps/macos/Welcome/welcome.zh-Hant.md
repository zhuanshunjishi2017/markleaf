# 歡迎來到 MarkLeaf

MarkLeaf 是一款專注寫作與排版的 Markdown 編輯器。這份可編輯文件會帶你快速熟悉常用功能，你可以直接修改內容並觀察效果。

## 開始寫作

1. 選擇「檔案 > 新增文件」，或按 `Command+N`。
2. 使用視窗底部的 `</>` 按鈕切換視覺化模式與原始碼模式。
3. 按 `Command+S` 儲存；第一次儲存時需要選擇檔名和位置。
4. 開啟資料夾作為工作區後，可以在左側側欄中瀏覽、搜尋和管理文件。

| 操作 | 快速鍵 |
| --- | --- |
| 新增文件 | `Command+N` |
| 開啟文件 | `Command+O` |
| 儲存文件 | `Command+S` |
| 尋找與取代 | `Command+F` |
| 復原 | `Command+Z` |
| 重做 | `Shift+Command+Z` |

## Markdown 基礎

### 標題與大綱

在原始碼模式中，使用 `#` 建立標題：

```markdown
# 一級標題
## 二級標題
### 三級標題
```

標題會自動出現在大綱中。按一下大綱項目即可跳到對應位置。

### 行內格式

- `**粗體**` 顯示為 **粗體**
- `*斜體*` 顯示為 *斜體*
- `~~刪除線~~` 顯示為 ~~刪除線~~
- `` `行內程式碼` `` 顯示為 `行內程式碼`
- 還可以使用底線、連結和格式刷

### 清單

1. 撰寫內容
2. 檢查格式
3. 儲存並匯出

- [x] 開啟 MarkLeaf
- [ ] 建立第一篇文件
- [ ] 嘗試匯出為 HTML 或 PDF

游標位於清單項目中時，按 `Tab` 增加縮排，按 `Shift+Tab` 減少縮排。

### 引用與程式碼區塊

> 好的工具應該讓你看見內容，而不是工具本身。

```swift
let message = "Hello, MarkLeaf!"
print(message)
```

## 豐富內容

### 公式

行內公式寫作 `$E=mc^2$`，顯示為 $E=mc^2$。

段落公式可以單獨成段：

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

### 腳註

正文中的閉合引用會顯示為上標[^1]。按住 `Command` 點按引用，可以在引用與定義之間跳轉。

[^1]: 腳註支援 **粗體**、*斜體*、~~刪除線~~、`行內程式碼`、[連結](https://github.com/zhuanshunjishi2017/markleaf)和公式 $x^2+y^2$。

## 自訂閱讀與寫作體驗

在「顯示方式」選單中可以切換排版樣式、顏色主題、縮放、側欄和專注模式。工作區與大綱標籤之間的切換會使用目前的顏色主題，並支援快速反向切換。

狀態列會顯示檔案編碼、換行符號、編輯模式和縮放比例。切換編碼前請先儲存重要內容；「重新讀取」會按新編碼重新解讀檔案，「儲存編碼」會保留目前內容並以新編碼儲存。
