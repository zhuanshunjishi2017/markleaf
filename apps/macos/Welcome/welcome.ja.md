# MarkLeaf へようこそ

MarkLeaf は、文章作成と美しい組版に集中できる Markdown エディタです。この文書は編集可能です。内容を変更しながら機能を試してみてください。

## 書き始める

1. 「ファイル > 新規ドキュメント」を選ぶか、`Command+N` を押します。
2. ウインドウ下部の `</>` ボタンで、ビジュアルモードとソースモードを切り替えます。
3. `Command+S` で保存します。初回はファイル名と保存先を選択します。
4. フォルダをワークスペースとして開くと、サイドバーから文書の閲覧、検索、管理ができます。

| 操作 | ショートカット |
| --- | --- |
| 新規ドキュメント | `Command+N` |
| ドキュメントを開く | `Command+O` |
| 保存 | `Command+S` |
| 検索と置換 | `Command+F` |
| 元に戻す | `Command+Z` |
| やり直す | `Shift+Command+Z` |

## Markdown の基本

### 見出しとアウトライン

ソースモードでは、`#` を使って見出しを作成します。

```markdown
# 見出し 1
## 見出し 2
### 見出し 3
```

見出しはアウトラインに自動表示されます。項目を選ぶと、その位置へ移動できます。

### インライン書式

- `**太字**` は **太字** と表示されます
- `*斜体*` は *斜体* と表示されます
- `~~取り消し線~~` は ~~取り消し線~~ と表示されます
- `` `インラインコード` `` は `インラインコード` と表示されます
- 下線、リンク、書式のコピーも利用できます

### リスト

1. 内容を書く
2. 書式を確認する
3. 保存して書き出す

- [x] MarkLeaf を開く
- [ ] 最初の文書を作成する
- [ ] HTML または PDF への書き出しを試す

リスト項目内で `Tab` を押すとインデントし、`Shift+Tab` でインデントを戻します。

### 引用とコードブロック

> 良い道具は、道具そのものではなく内容を見せてくれます。

```swift
let message = "Hello, MarkLeaf!"
print(message)
```

## リッチコンテンツ

### 数式

インライン数式は `$E=mc^2$` と書くと $E=mc^2$ と表示されます。

長い数式は独立した段落にできます。

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

### 脚注

本文中の閉じた参照は上付き文字として表示されます[^1]。`Command` を押しながらクリックすると、参照と定義の間を移動できます。

[^1]: 脚注では **太字**、*斜体*、~~取り消し線~~、`インラインコード`、[リンク](https://github.com/zhuanshunjishi2017/markleaf)、数式 $x^2+y^2$ を使用できます。

## 自分に合った表示にする

「表示」メニューでは、書体スタイル、カラーテーマ、ズーム、サイドバー、集中モードを変更できます。ワークスペースとアウトラインの切り替えには現在のテーマが使われ、すばやく逆方向へ切り替えても滑らかに追従します。

ステータスバーには文字コード、改行コード、編集モード、ズームが表示されます。文字コードを変更する前に重要な内容を保存してください。「再読み込み」は選択した文字コードでファイルを読み直し、「エンコーディングを保存」は現在の内容を保ったまま選択した文字コードで保存します。

この文書を閉じて新しい文章を書き始めることも、そのまま編集して機能を試すこともできます。
