# 欢迎来到 MarkLeaf

MarkLeaf 是一款专注写作与排版的 Markdown 编辑器。这份可编辑文档会带你快速熟悉常用功能，你可以直接修改内容并观察效果。

## 开始写作

1. 选择“文件 > 新建文档”，或按 `Command+N`。
2. 使用窗口底部的 `</>` 按钮切换可视化模式与源码模式。
3. 按 `Command+S` 保存；第一次保存时需要选择文件名和位置。
4. 打开文件夹作为工作区后，可以在左侧侧栏中浏览、搜索和管理文档。

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | `Command+N` |
| 打开文档 | `Command+O` |
| 保存文档 | `Command+S` |
| 查找与替换 | `Command+F` |
| 撤销 | `Command+Z` |
| 重做 | `Shift+Command+Z` |

## Markdown 基础

### 标题与大纲

在源码模式中，使用 `#` 创建标题：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

标题会自动出现在大纲中。单击大纲项目即可跳转到对应位置。

### 行内格式

- `**粗体**` 显示为 **粗体**
- `*斜体*` 显示为 *斜体*
- `~~删除线~~` 显示为 ~~删除线~~
- `` `行内代码` `` 显示为 `行内代码`
- 还可以使用下划线、链接和格式刷

### 列表

1. 编写内容
2. 检查格式
3. 保存并导出

- [x] 打开 MarkLeaf
- [ ] 创建第一篇文档
- [ ] 尝试导出为 HTML 或 PDF

光标位于列表项中时，按 `Tab` 增加缩进，按 `Shift+Tab` 减少缩进。

### 引用与代码块

> 好的工具应当让你看见内容，而不是工具本身。

```swift

print(message)
```

## 丰富内容

### 公式

行内公式写作 `$E=mc^2$`，显示为 $E=mc^2$。

段间公式可以单独成段：

$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx=\sqrt{\pi}$$

### 脚注

正文中的闭合引用会显示为上标[^1]。按住 `Command` 单击引用，可以在引用与定义之间跳转。

[^1]: 脚注支持 **粗体**、*斜体*、~~删除线~~、`行内代码`、[链接](https://github.com/zhuanshunjishi2017/markleaf)和公式 $x^2+y^2$。

## 自定义阅读与写作体验

在“视图”菜单中可以切换排版样式、颜色主题、缩放、侧栏和专注模式。工作区与大纲标签之间的切换会使用当前颜色主题，并支持快速反向切换。

状态栏会显示文件编码、换行符、编辑模式和缩放比例。切换编码前请先保存重要内容；“重新读取”会按新编码重新解释文件，“保存编码”会保留当前内容并用新编码保存。

现在可以关闭这份文档并开始写作，也可以继续修改它来试验各种功能。
