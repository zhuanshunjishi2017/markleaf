# MarkLeaf 更新履歴

## 1.7.6 — 2026-09-12

### 変更

- ワークスペースツリー、一覧、検索を `.md` / `.txt` に統一しました。プレビューと検索では、HTML タグ間隔と文字参照の復号も統一しています。
- 「HTML をコピー」はソース文字列をコピーします。通常の書式付きコピーでは引き続きテキストと HTML を提供します。
- ツリーと文書一覧のスキャンは独立して実行されます。ワークスペースを切り替えたり閉じたりした後、キャンセルされた古いスキャン結果は反映されません。

### 修正

- PDF、画像、アーカイブなどの非テキストファイルのみを含むフォルダを展開した際の更新ループを修正しました。
- 廃止済みの Web 検索バーへの参照によって起動が中断し、編集領域が空白になる問題を修正しました。
- 前回のセッションから復元したウィンドウで、ファイルを開く処理とダイアログの親ウィンドウが正しく接続されず、選択したファイルが読み込まれない問題を修正しました。
- 生成された PDF のテキスト内で一部の見出しを特定できない場合に、書き出し画面がクラッシュする問題を修正しました。
- ダークモードでアプリを起動、エディターを再起動、または新しいタブを作成したときに、エディターが白く点滅する問題を修正しました。
- ライト/ダークテーマを切り替えたときに、タイトルバー、タブバー、ステータスバーが同期して更新されない問題を修正しました。
- ソースモードで「スクロールバーを自動的に隠す」が機能しない問題を修正しました。

## 1.7.5 — 2026-09-10

### 追加

- 1 つのウィンドウで複数のタブを開けるようにしました。
- 完全なセッション復元を追加しました。次回起動時にウィンドウ、タブ、カーソル、スクロール位置を復元します。
- ファイルメニューに「ワークスペースで表示」「ファイルパスをコピー」「内容をクリップボードにコピー」「Finder に表示」「共有」を追加し、ファイル操作を行いやすくしました。
- コードブロック右上に「コピー」と「言語」のコントロールを追加しました。
- YAML フロントマターの入力支援と書式チェックを追加し、基本・応用のサンプル文書を用意しました。
- 数式のオーバーレイ編集と数式番号を追加し、`\(...\)` の行内数式と `\[...\]` の段落間数式の認識、レンダリング、書き出しに対応しました。
- Mermaid が default / dark / neutral の 3 テーマに対応し、テーマやスタイルの切り替え後に自動で再描画します。
- 「Markdown の動作」設定ウィンドウを追加しました。エスケープ、空行でのブロック終了、Shift+Enter の強制改行、コードフェンス、強調マーカー、リストマーカーを設定できます。
- 「最大幅の制限を無視」「コードのシンタックスハイライトを表示」などの設定を追加しました。文書内のローカルリンクから該当ファイルを直接開けます。
- サイドバーにワークスペースファイルのプレビューと全文検索を追加しました。
- 「外部ファイルを開く方法」と「ワークスペースのファイルを開く方法」の設定を追加し、同じファイルを重複して開かないようにしました。
- サイドバーからファイルやフォルダーの名前変更・移動ができ、開いているタブのパスも追従します。
- 「書き出し」に「見出しをページ最下部に置かない」「表をページで分割しない」などのページ分割オプションを追加しました。
- 統合された「テーマ設定…」ウィンドウを追加しました。カラーテーマとスタイルをページで分け、カラーテーマはライト/ダークでグループ化してプレビューを表示します。システムに合わせる、既定のライト/ダークテーマ、テーマの追加、テーマフォルダーを開くに対応します。
- 「オプションフォントをインストール…」ウィンドウを追加しました。スタイルに不足しているフォントがある場合は通知と「フォント不足」バッジを表示します。

### 変更

- メニューバーをファイル / 編集 / 挿入 / 書式 / 表示 / ヘルプに再編成しました。
- エディタのコンテキストメニューを機能ごとに整理し、ユーザーが設定したショートカットを表示するようにしました。
- HTML / PDF の書き出し時にローカル画像をファイルへ埋め込めるようにし、長い画像は自動で分割します。
- 「書式 → コードブロック」で任意の識別子を指定できるようにしました。
- 「エディタ集中モード」は表示領域の比率に応じて現在以外の段落を薄くします。「タイプライターモード」は表示領域の約 42% にカーソルを保ち、短い文書では強制的にスクロールしません。
- エディタのスクロール位置がタブやモードの切り替え後も保持されます。
- 組み込みテーマの識別子を移行し、以前のテーマ設定は新しいテーマに自動で対応します。
- ワークスペースのサイドバーを広げ、行の情報密度を調整しました。ファイル名を優先し、時刻表示をより簡潔にしています。
- 「書き出し」で画像としての書き出しに対応しました。

### 修正

- 「ミニマルモード」を有効にした後もメニューで未チェックと表示される問題を修正しました。
- ソースモードで「エディタ集中モード」「タイプライターモード」や表示側の挿入・書式コマンドが実行できてしまう問題を修正しました。
- エディタのコンテキストメニューに元に戻す、やり直す、すべて選択がなく、コマンドにショートカットが表示されない問題を修正しました。
- ソースモードでサブメニューの親項目（画像、表の挿入、Mermaid、段落操作、段落スタイル、リスト、アラート）がまとめて無効にならない問題を修正しました。
- 文書が空のときに「内容をクリップボードにコピー」が選べる問題を修正しました。ファイルメニュー、タブのコンテキストメニュー、ワークスペースファイルのコンテキストメニューで挙動が揃います。
- すべてのタブを閉じるとウィンドウまで閉じてしまい、ステータスバーに文書情報が残る問題を修正しました。
- タブのドラッグ中に持ち上げやドロップが乱れ、アニメーションが繰り返し再生される問題を修正しました。
- サイドバーの空状態、タブの選択状態、ダークテーマでサイドバーを表示したときのちらつきを修正しました。
- 下線とリテラルのプラス記号の競合による文字化けを修正しました。`C++17`、`i++`、`++i` などが編集後や再起動後に書き換わったり欠落したりしません。
- 段落間数式が早い段階で行内数式に変換される問題と、数式前後の数字テキストが誤判定される問題を修正しました。
- Mermaid のフォント計測によるレンダリングとレイアウトの揺れを修正しました。
- 書き出しプレビューが現在のタブに追従しない問題、および画像書き出しのレイアウトと検証の問題を修正しました。
- 「段落ブロックハンドル」をオフにして起動したときに、編集領域でハンドルが一瞬表示される問題を修正しました。
- 「コードのシンタックスハイライトを表示」をオフにして文書を開いたときに、コードブロックが一瞬ハイライト表示される問題を修正しました。
