# MarkLeaf 更新履歴

## 1.2.5 — 2026-08-19

### 新機能

- ソースモードで元に戻す／やり直しに対応し、貼り付けを常にプレーンテキストとして扱います。
- 「プレーンテキストとして貼り付け」（`⌘⇧V`）を追加し、コピー関連メニューを「コピー／貼り付け形式」に統一しました。
- ソースモードで CommonMark 規則に反する閉じたアスタリスク記号を検出し、リテラルとして残すか HTML タグへ変換できます。確認ダイアログには「次回から表示しない」と「詳細を見る」を用意しました。
- Markdown 生成時に太字・斜体記号の危険な境界を検出し、必要に応じて HTML タグへ変換して再読み込み後のアスタリスク露出を防ぎます。
- 読み取り専用モードではネイティブコンテキストメニューを制限し、ソースモードの編集操作を無効にします。
- HTML と PDF の書き出しウィンドウを統合し、「前回の設定で書き出す」を追加しました。
- 書き出し設定を保存し、PDF のヘッダー／フッターでタイトル・ページ番号・総ページ数・カスタム内容を使用できます。
- 明るい「ソルトレモン（saltlemon）」配色テーマを追加しました。

### 変更

- 基本レイアウトの最小マージン段階を削除し、左右のマージンを少し縮小。書き出し画面では現在のスタイルと配色を初期値にします。
- PDF ヘッダー／フッターは選択したレイアウトスタイルのフォントを使い、本文の 0.875 倍、上下間隔 6mm で表示します。
- PDF 書き出しで本文コンテナの最大幅制限を外し、表が印刷可能領域まで広がるようにしました。手動で余白を変更するとカスタム段階に切り替わります。
- 最後のエディタウィンドウを閉じても MarkLeaf を Dock に残し、Dock アイコンをクリックすると既存ウィンドウを復元するか空白ウィンドウを作成します。

### 修正

- ソースモードで HTML／リッチテキストを貼り付けると空になる問題、プレーンテキスト貼り付け後にカーソルがずれる問題を修正しました。
- ビジュアルモードで全角記号・文字・数字を入力するとカーソルが飛ぶ問題を修正しました。
- 画像をコピーして再度貼り付けると空白になったりタイトルだけが残ったりする問題を修正しました。
- システムのカラーに従う設定を確定してもテーマがすぐに適用されない問題を修正しました。
- 読み取り専用モードでフロントエンドの編集メニューや編集操作が残る問題を修正しました。
- PDF ヘッダー／フッターが選択したフォントを使わない問題、表が印刷可能幅いっぱいに広がらない問題を修正しました。
- macOS Dock アイコンのセーフエリアを調整し、隣接するアプリケーションと視覚的な大きさを揃えました。

## 1.2.4 — 2026-08-17

### 新機能

- 表と画像のタイトルに対応：表タイトルは表の上、画像タイトルは画像の下に中央揃えで表示。表や画像を右クリックしてタイトルを編集でき、太字・斜体・取り消し線などのインライン書式にも対応。
- 段落間数式に番号（例：1 や 1.1）を設定可能：数式編集時に番号を指定すると、右揃えで表示されます。

### 変更

- LaTeX レイアウトスタイルで、`## *テキスト*`（斜体のレベル 2 見出し）を著者・連絡先の記述として扱い、中央揃えの本文として表示。

### 修正

- 複数の表タイトルを含む文書の読み込み時にエディタ初期化が失敗し、メニューバーの大半が無効になる問題を修正。
- 表・画像タイトルの色とサイズがエディタと書き出しで異なる問題を修正。

## 1.2.3 — 2026-08-16

### 新機能

- 書き出しダイアログが PDF / HTML の両形式に対応し、どちらもリアルタイムプレビュー付き：書き出し前にレイアウトを確認し、用紙・向き・余白（カスタム余白対応）・スタイル・配色を調整できます。

### 修正と改善

- PDF 書き出しで長い数式がはみ出したり途切れたりする問題を修正。
- 表示言語を英語に切り替えた際にアプリがクラッシュする問題を修正。

## 1.2.2 — 2026-08-15

### 新機能

- PDF 書き出しは選択した場所に直接保存されるようになり、システム印刷パネルは表示されません。
- 「プリント…」機能（⌘P）を追加：システム印刷パネルで現在の文書を印刷し、印刷時は常に明るい背景と濃い文字を使用します。
- 「ショートカットキー」ウィンドウでカスタムショートカットを設定でき、即座に反映され永続化されます。

### 修正と改善

- フォーカスモードのショートカットキーを F11 から ⌘⇧F に変更し、システムの「デスクトップを表示」との競合を回避します。
- 「ショートカットキー」ウィンドウが開いた直後に細長い形状に潰れる問題を修正。
- 「ショートカットキー」ウィンドウの「クリア」でショートカットを解除できない問題を修正。
- 「フォント設定」ウィンドウが大きすぎる問題を修正。
- 段落メニューの箇条書き・番号付きリスト・タスクリストが適用できない問題を修正。
- 見出しメニュー項目の表記（例：「一級級標題」）で「級」が重複する問題を修正。
- リスト項目で段落ブロックハンドルが表示されず、書式ペインターが使えない問題を修正。
- システム印刷パネルで「キャンセル」をクリックした際にアプリがクラッシュする問題を修正。
- サイドバーを閉じた状態でソースモードの行番号と本文の間隔が広くなりすぎる問題を修正。

## 1.2.0 — 2026-08-14

### 新機能

- LaTeX 数式に対応：インライン `$...$` と段落間 `$$...$$`。可視化編集で閉じた数式を KaTeX で自動レンダリング。
- 段落メニューに「段落間数式」、書式メニューに「行内数式」を追加。選択範囲はそのまま数式化、未選択時は LaTeX 入力ダイアログを表示。
- 数式のコンテキストメニューで編集・インライン/段落間の変換・削除に対応。
- コンテキストメニューを状況に応じて動的に変更：ソースモード・表・数式・コードブロック・見出しで操作を出し分け。
- 「更新履歴」を新しいウィンドウで読み取り専用表示に変更。編集中の文書を置き換えず、誤編集や保存プロンプトも発生しません。
- HTML/PDF エクスポートで数式をレンダリング（KaTeX CSS とフォントを内包、woff2 のみで軽量化）。

### 修正と改善

- ソースモードで I 型カーソルが見えなくなる問題を修正。
- プレーンテキスト（.txt）文書はソースモード固定になり、「表示 > ソースモード」メニューを無効化。
- メニューバー「表の挿入 > カスタム表」ダイアログが一瞬で閉じる問題を修正。「行数/列数」ラベルと入力欄を整列。
- サイドバー検索フィールドの高さをわずかに拡大。
- 復元ウィンドウの「すべて破棄 / 選択を破棄」ボタンを標準の白いボタンスタイルに戻す。
- PDF エクスポートをシステム印刷パネル経由に変更。用紙サイズ・向き・余白をパネルで調整してから PDF として保存できます。

### 変更

- 印刷スタイルが「最大幅」設定に追従、PDF の表は内容に合わせて幅が変化。

## 1.1.7 — 2026-08-13

- サイドバーで Markdown/TXT ファイルを名前または内容から検索し、アウトライン見出しを絞り込めます。
- 段落ブロックハンドルのネイティブ操作メニューと、段落前後への行挿入を追加しました。
- タスクリストのチェックボックスを整列し、日本語印刷では Yu Mincho/Yu Gothic を使用します。

## 1.1.6 — 2026-08-12

- 外部から開いたファイルを新規ウィンドウまたは現在のウィンドウで開く設定を追加。すでに開いているファイルは重複せず、対応ウィンドウをアクティブ化します。
- 変更済みドキュメントを閉じる・置き換える・終了する際に、保存／保存しない／削除／キャンセルを確認。該当設定が有効で書き込みに成功した場合のみ自動保存します。
- 「書式」メニューとエディタのコンテキストメニューに、1 回限りの「書式のコピー/貼り付け」を追加。
- 4 つのインターフェース言語で Markdown 更新履歴を提供。
- 復元ダイアログを完全にローカライズ。
- 「アウトライン」のフォントサイズとグレーの選択背景を「ワークスペース」と統一。
- 「アウトライン」の選択が最初のクリックで表示されるよう修正。
- 言語切り替え後も環境設定の現在のページとウィンドウ位置を維持。

## 1.1.5 — 2026-08-12

- 簡体字・繁体字・日本語・韓国語の字形を選べる「CJK 優先フォント」を追加。
- 表示メニューに「フォーカスモード」を追加（F11 で開始、Esc で終了）。
- エディタのフォント設定を専用の「フォント設定」ダイアログに統合。
- セリフ・サンセリフスタイルに Source Han/Noto CJK フォントのフォールバックを追加。
- アウトラインのフォントサイズとグレーの選択影をワークスペースと統一。
- モランディテーマのページ背景色を更新。

## 1.1.4 — 2026-08-11

- ライト／ダークモードそれぞれに既定テーマを設定可能に。
- 左のワークスペースでドラッグ移動、Finder へのドラッグでコピーに対応。
- サイドバーの展開状態とアクティブなタブを復元。
- ドラッグとの競合を避けるため、ファイルはマウスを離したときに開くよう変更。
- 言語切り替え後、ネイティブ UI を即時更新。

## 1.1.3 — 2026-08-10

- スクロールバーの自動非表示がオフのとき、エディタのスクロールバーが太すぎてテーマ色が反映されない問題を修正。
- ダークモードでエディタの読み込み完了時に白くちらつく問題を修正。
- 終了時に 7 日前のログを自動クリーンアップ。
- 「更新内容」メニューを追加（エディタウィンドウ内で開く）。
