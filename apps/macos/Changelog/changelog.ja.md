# MarkLeaf 更新履歴

## 1.3.2 — 2026-08-23

- 「Mermaid 図表」機能を追加しました。```` ```mermaid ```` のフェンス付きコードブロックでフローチャートやシーケンス図などを描画し、エクスポート時は SVG としてインライン化されます。
- サイドバーが非表示のとき、ウィンドウ左端をドラッグしてサイズを変更するとサイドバーが意図せず再表示される問題を修正しました。
- サイドバーを非表示にして起動した後の初回表示で、サイドバーが意図せず一瞬表示される問題を修正しました。
- 書式のコピーがまれに適用されない問題を修正しました。
- 中文や句読点の隣にある太字斜体（`***…***`）が誤って解釈され、保存やモード切替後に文書が壊れる問題を修正しました。
- 文書内に「` ```mermaid `」という記述があると、Mermaid のソースコード内の `[*]` や `-->` が誤って解釈され、図が構文エラーになる問題を修正しました。

## 1.3.1 — 2026-08-22

- エンコーディング関連の設定を追加しました。環境設定では新規ファイルの既定エンコーディングを指定でき、ステータスバーでは現在の文書のエンコーディングを即座に変更できます。また、ファイルを最適なエンコーディングで開けるようになりました。

- 環境設定ウィンドウのレイアウトを微調整しました。
- ステータスバーの「ビジュアル」をモードメニューに変更しました。

- 「MarkLeaf について」のバージョン表示を、バージョン番号とビルド番号を組み合わせた形式に変更しました。
- 「MarkLeaf について」のビルド番号が 42 に固定されていた問題を修正しました。実行中のアプリバンドルから実際のバージョン情報を読み取り、ビルドスクリプトは既定で Git のコミット数をビルド番号に使用します。
- ズーム中も現在表示している文書位置を維持するようにしました。
- 「MarkLeaf について」ウィンドウを現在の画面中央より上に表示し、よりコンパクトなレイアウトへ変更しました。GitHub の完全なリンクと著作権情報を表示し、著作権行の色と間隔も調整しました。

- 「漢字優先字形」を「フォント設定」に移動しました。
- 簡体字中国語、繁体字中国語、英語、日本語の環境設定にそれぞれ安定したウィンドウ幅を設定しました。ページ切り替え時は高さだけを変更し、英語と日本語の長いラベルが隠れる問題も修正しました。
- スクロールバーの自動非表示で滑らかなフェードイン／フェードアウトを追加し、システムの「視差効果を減らす」が有効な場合はアニメーションを自動的に無効にします。
- 「書式」と「段落」メニューの有効条件を統一しました。選択範囲がない場合は太字、斜体、下線、取り消し線を無効にし、インラインコードは入力ダイアログから挿入できます。段落コマンドは現在の段落、または選択範囲が含む段落へ一貫して適用されます。
- メニューバーとショートカット設定の「検索」と「置換」を「検索と置換」に統合し、既定のショートカットは ⌘F のままにしました。同じウィンドウ内で置換機能を滑らかに展開・折りたたみできます。

- 段落間数式、インラインコード、注釈の各ダイアログの入力欄を、環境設定と同じ控えめな角丸の長方形スタイルに統一し、段落間数式の番号ラベルと入力欄の間隔も縮めました。注釈番号は Esc で編集中の内容を元に戻し、フォーカスが外れた時点で直ちに検証します。
- レンダリング済みの LaTeX 数式を選択すると前方のテキストも一緒に選択される問題を修正しました。

- テキストが選択されていないときにも「コピー」と「コピー形式」が使用できる問題を修正しました。
- 「検索と置換」ウィンドウのテキスト欄でシステムショートカットが使用できない問題を修正しました。

- ワークスペースを開いた後、サイドバーのボタンから別のフォルダを選択するとクラッシュする問題を修正しました。
- サイドバー非表示で起動した後の初回表示で、「ワークスペースが開かれていません」の位置ずれ、「フォルダを開く」ボタンの消失、サイドバー幅の異常が発生する問題を修正しました。

- サイドバーが非表示のとき、ファイルを開くか保存するとサイドバーが意図せず再表示される問題を修正しました。

## 1.3.0 — 2026-08-20

### 追加

- 検索結果にフォルダアイコンとキーワード周辺の文脈を表示します。結果を開くと検索を終了し、ワークスペースツリーで対象ファイルを展開して選択します。
- ステータスバーをカスタマイズ可能に：サイドバー切替ボタン、コマンド状態、文字数、ブロック種類、カーソル位置、エンコーディング、改行コード、ソース/ビジュアル切替、ズーム倍率を個別に表示/非表示できます。
- ステータスバーの文字数をクリックすると詳細な文書統計（文字数、選択文字数、総文字数、空白以外の文字数、CJK 文字数、英単語数、数式数、コード行数、段落数、行・列）を表示します。
- ワークスペースの右クリックメニューを拡充：新規ファイル、新規フォルダ、パスをコピー、Finder に表示、新しいウィンドウで開く、名前を変更、削除、ツリー/リスト切替、並べ替え、更新、ワークスペースを閉じる。
- ドキュメントリストモードで所在フォルダと更新日時を表示し、ファイル名または更新日時による昇順/降順の並べ替えに対応しました。
- Finder から .md/.txt/.markdown ファイルをワークスペースにドラッグ＆ドロップでコピーできるようにしました。
- ワークスペースツリーで Return キーを押すとファイルを開き、フォルダでは展開/折りたたみができます。
- 画像の右クリックメニューと書式メニューを拡充：画像を変更、サイズ変更（100%/75%/90%/50%）、時計回りに回転、画像を別名で保存。
- ファイルメニューに「読み取り専用で開く…」を追加しました。
- 段落メニューに「段落の書式をクリア」を追加しました。
- 環境設定の「外観」に「スクロールバーを自動的に隠す」を追加しました。

### 変更

- 初回起動時に Markdown/テキストファイルの関連付けを自動で引き継がず、ユーザーが明示的に有効にした場合のみ MarkLeaf を既定エディタにします。
- ステータスバーのコマンドフィードバックと文書状態を独立したフィールドに分離し、互いに上書きしないようにしました。「一時表示」は 5 秒後に自動でクリアされます。
- 「ステータスバーをカスタマイズ」ウィンドウをコンパクトなレイアウトに変更し、見出し、各項目、コマンド状態の表示設定の配置と間隔を統一しました。
- PDF と HTML を 1 つの「書き出す…」ウィンドウに統合しました。ファイルメニューの書き出し項目は 1 つに整理し、「前回の設定で書き出す」は引き続き利用できます。
- 書き出し画面では現在のレイアウトスタイルと配色テーマ、標準余白を初期値にします。1 回の書き出しだけ別の配色を選択でき、「前回の設定で書き出す」では保存済みの配色を維持します。
- 検索をキャンセルすると、ディレクトリ走査とファイル読み込みを停止します。

### 修正

- 検索結果をクリックしても、対象ファイルをワークスペースツリーに表示できないことがある問題を修正しました。
- ワークスペースの右クリックメニューで新規作成・名前変更・削除・並べ替えなどができない問題を修正しました。
- Finder からワークスペースへのドラッグ＆ドロップが拒否される問題を修正しました。
- ドキュメントリストの情報不足と並べ替え不能の問題を修正しました。
- キャンセルした検索がファイルを読み続け、ディスクと CPU を消費する問題を修正しました。
- ステータスバーにエンコーディング・改行・モード切替・ズームがなく、カスタマイズもできない問題を修正しました。
- 「ステータスバーをカスタマイズ」ウィンドウの左側に大きな空白があり、見出しが揃わず、ラベルとプルダウンの間隔が広すぎる問題を修正しました。
- ファイルメニューに旧「書き出し形式」サブメニューが重複して表示される問題を修正しました。
- 書き出し画面が現在のテーマを無視して以前のダーク配色を初期選択し、標準余白が「カスタム」と表示される問題を修正しました。
- 読み取り専用モードで ⌘A 全選択・⌘C コピーのショートカットが効かない問題と、Esc やフォーカス喪失で選択が解除されずハイライトが残る問題を修正しました。

## 1.2.6 — 2026-08-19

### 新機能

- 書き出しウィンドウの下部に「前回の設定で書き出す」ボタンを追加し、前回の設定をそのまま使って書き出せます。
- ヘッダー／フッターのカスタム入力欄を角丸にし、プリセットで「カスタム」を選んだときだけ対応するドロップダウンの下に表示され、他の項目はなめらかに移動します。
- 編集メニューとコンテキストメニューのクリップボード項目を「切り取り、コピー、貼り付け、プレーンテキストとして貼り付け、コピー形式」に統一し、選択・クリップボード内容・読み取り専用状態に応じて自動的に無効化します。
- 脚注に対応：`[^x]` は上付き参照、`[^x]:` 段落は脚注定義として表示し、HTML/PDF 書き出しでは専用構造を生成します。
- 段落メニューに「注釈を挿入」を追加：番号とテキストを入力すると、カーソル位置に参照、文末に定義を挿入します。
- ⌃ キーを押しながら脚注参照をクリックすると対応する定義へ移動し、定義がない場合は明確な警告を表示します。
- 脚注定義段落のコンテキストメニューに「注釈番号をリセット」を追加し、同じ番号の参照と定義をまとめて変更できます。

### 修正

- サイドバーを非表示のまま新規ファイルを開くと、収納アニメーションが毎回再生される問題を修正しました。
- ダークテーマで PDF を書き出すと本文部分だけが暗くなり、余白が白いままになる問題を修正しました。
- 書き出しプレビューの再生成時に画面がちらつき、総ページ数の表示が消えたり現れたりする問題を修正しました。

## 1.2.5 — 2026-08-19

### 新機能

- ソースモードで元に戻す／やり直しに対応し、貼り付けを常にプレーンテキストとして扱います。
- 「プレーンテキストとして貼り付け」（`⌘⇧V`）を追加し、コピー関連メニューを「コピー／貼り付け形式」に統一しました。
- ソースモードで CommonMark 規則に反する閉じたアスタリスク記号を検出し、リテラルとして残すか HTML タグへ変換できます。確認ダイアログには「次回から表示しない」と「詳細を見る」を用意しました。
- Markdown 生成時に太字・斜体記号の危険な境界を検出し、必要に応じて HTML タグへ変換して再読み込み後のアスタリスク露出を防ぎます。
- 読み取り専用モードではネイティブコンテキストメニューを制限し、ソースモードの編集操作を無効にします。
- HTML と PDF の書き出しウィンドウを統合し、「前回の設定で書き出す」を追加しました。
- 書き出し設定を保存し、PDF のヘッダー／フッターでタイトル・ページ番号・総ページ数・カスタム内容を使用できます。
- 明るい「ソルトレモン（saltlemon）」配色テーマを追加しました。

### 変更

- 基本レイアウトの最小マージン段階を削除し、左右のマージンを少し縮小。書き出し画面では現在のスタイルと配色を初期値にします。
- PDF ヘッダー／フッターは選択したレイアウトスタイルのフォントを使い、本文の 0.875 倍、上下間隔 6mm で表示します。
- PDF 書き出しで本文コンテナの最大幅制限を外し、表が印刷可能領域まで広がるようにしました。手動で余白を変更するとカスタム段階に切り替わります。
- 最後のエディタウィンドウを閉じても MarkLeaf を Dock に残し、Dock アイコンをクリックすると既存ウィンドウを復元するか空白ウィンドウを作成します。

### 修正

- ソースモードで HTML／リッチテキストを貼り付けると空になる問題、プレーンテキスト貼り付け後にカーソルがずれる問題を修正しました。
- ビジュアルモードで全角記号・文字・数字を入力するとカーソルが飛ぶ問題を修正しました。
- 画像をコピーして再度貼り付けると空白になったりタイトルだけが残ったりする問題を修正しました。
- システムのカラーに従う設定を確定してもテーマがすぐに適用されない問題を修正しました。
- 読み取り専用モードでフロントエンドの編集メニューや編集操作が残る問題を修正しました。
- PDF ヘッダー／フッターが選択したフォントを使わない問題、表が印刷可能幅いっぱいに広がらない問題を修正しました。
- macOS Dock アイコンのセーフエリアを調整し、隣接するアプリケーションと視覚的な大きさを揃えました。
