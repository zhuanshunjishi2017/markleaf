# MarkLeaf 更新內容

## 1.2.5 — 2026-08-19

### 新增

- 原始碼模式支援復原、重做，並統一以純文字方式處理貼上內容。
- 新增「貼上為純文字」（`⌘⇧V`），並將複製選單統一為「複製/貼上為」。
- 原始碼模式支援偵測不符合 CommonMark 規則的閉合星號標記，可選擇保留字面值或轉為 HTML 標籤；提示視窗支援「不再提示」與「了解詳情」。
- 產生 Markdown 時自動偵測粗體、斜體標記的危險邊界，必要時轉為 HTML 標籤，避免重新載入後暴露星號原始碼。
- 唯讀模式使用受限的系統右鍵選單，並停用原始碼模式編輯操作。
- 合併 HTML 與 PDF 匯出視窗，並新增「依上次設定匯出」。
- 匯出設定會持久化儲存；PDF 匯出支援頁首頁尾、文件標題/頁碼/總頁數佔位符及自訂內容。
- 新增淺色「檸檬海鹽（saltlemon）」配色方案。

## 1.2.6 — 2026-08-19

### 新增

- 匯出視窗底部新增「依上次設定匯出」按鈕，可直接沿用上次的匯出設定。
- 頁首/頁尾的自訂文字框改為圓角樣式，僅在預設選擇「自訂」時顯示在對應下拉框下方，其他選項自動下移並帶平滑動畫。
- 編輯選單與右鍵選單的剪貼板指令統一為剪下、拷貝、貼上、貼上為純文字和「複製為」，並依是否有選取文字、剪貼板內容與唯讀狀態自動置灰。
- 新增腳註支援：`[^x]` 顯示為上標引用，`[^x]:` 段落顯示為腳註定義；匯出 HTML/PDF 時產生專用結構。
- 段落選單新增「插入註釋」指令，可填寫註釋編號與註釋文字，在目前位置插入引用並在文末加入定義。
- 按住 ⌃ 鍵點擊腳註引用可跳至對應定義；定義缺失時會明確提示。
- 腳註定義段落右鍵選單新增「重設註釋編號」，可批次替換相同編號的引用與定義。

### 修復

- 修復隱藏側邊欄時開啟新檔案會重複播放收合動畫的問題。
- 修復深色主題匯出 PDF 時僅正文區域為深色、頁邊距區域仍為白色的問題。
- 修復匯出預覽重新產生時頁面閃爍、總頁數文字消失又出現的問題。

### 更改

- 基礎排版自適應邊距刪除最小一檔，並適度減小左右邊距；匯出視窗預設同步目前排版樣式與配色。
- PDF 頁首頁尾使用所選排版樣式字型，字號為正文標準字號的 0.875，上下間距調整為 6mm。
- PDF 匯出移除正文容器的最大寬度限制，使表格可擴展至頁邊距範圍；自訂邊距修改後自動切換至自訂檔位。
- 關閉最後一個編輯視窗後，MarkLeaf 繼續駐留在 Dock；點擊 Dock 圖示時恢復既有視窗，或建立新的空白視窗。

### 修復

- 修復原始碼模式貼上 HTML/富文本內容為空、純文字貼上後游標位置異常後移的問題。
- 修復視覺化模式輸入全形符號、全形字母、全形數字時游標異常跳動的問題。
- 修復複製圖片後再次貼上變為空白或僅保留圖片標題文字的問題。
- 修復跟隨系統顏色模式點擊確定後主題不會立即套用的問題。
- 修復唯讀模式仍可能彈出前端編輯選單或回應編輯操作的問題。
- 修復 PDF 頁首頁尾字型未依目前排版樣式渲染，以及表格無法填滿可用寬度的問題。
- 調整 macOS Dock 圖示的安全邊距，使 MarkLeaf 與相鄰應用程式的視覺大小一致。

## 1.2.4 — 2026-08-17

### 新增

- 支援表格標題與圖片標題：表格標題顯示於表格上方，圖片標題顯示於圖片下方，均置中顯示；右鍵表格或圖片可編輯標題，標題支援粗體、斜體、刪除線等行內格式。
- 段落間公式支援編號（如 1 或 1.1）：編輯公式時設定編號，渲染時編號靠右對齊顯示。

### 更改

- LaTeX 排版樣式下，`## *文字*`（二級標題加斜體）作為作者/聯絡資訊寫法，渲染為置中普通正文。

### 修復

- 修復含多個表格標題的文件載入時編輯器初始化失敗、選單列大部分不可用的問題。
- 修復表格/圖片標題在編輯器與匯出中顏色、字型大小不一致的問題。

## 1.2.3 — 2026-08-16

### 新增

- 匯出對話框支援 PDF / HTML 兩種格式，均帶即時預覽：可在匯出前檢視版面、調整紙張/方向/頁邊距（支援自訂邊距）、樣式與配色。

### 修復與改進

- 修復長公式在 PDF 匯出中溢出或被截斷的問題。
- 修復切換介面語言為英文時應用程式閃退的問題。

## 1.2.2 — 2026-08-15

### 新增

- 匯出 PDF 直接儲存到所選位置，不再開啟系統列印面板。
- 新增「列印…」功能（⌘P）：透過系統列印面板列印目前文件，列印時強制淺色背景與深色文字。
- 「快速鍵」視窗支援自訂快速鍵，即時生效並持久化儲存。

### 修復與改進

- 專注模式快速鍵由 F11 調整為 ⌘⇧F，避免與系統「顯示桌面」衝突。
- 修復「快速鍵」視窗初始佈局異常（視窗被壓縮成窄條）的問題。
- 修復「快速鍵」視窗「清除」無法移除快速鍵的問題。
- 修復「字體設定」視窗過大的問題。
- 修復段落選單中無序列表、有序列表、任務列表無法套用格式的問題。
- 修復標題選單項文案（如「一級級標題」）多出「級」字的問題。
- 修復列表項不顯示段落區塊控制鈕、格式刷無法用於列表的問題。
- 修復在系統列印面板中點擊「取消」後應用程式閃退的問題。
- 修復原始碼模式下關閉側邊欄後行號與正文間隔過大的問題。

## 1.2.0 — 2026-08-14

### 新增

- 支援 LaTeX 數學公式：行內 `$...$` 與塊級 `$$...$$`，可視化編輯輸入閉合公式後自動渲染（KaTeX）。
- 段落選單新增「段間公式」、格式選單新增「行內公式」指令；選取文字時直接套用公式標記，未選取時彈窗輸入 LaTeX。
- 公式右鍵選單支援編輯、行內/塊級互轉、刪除。
- 右鍵選單依上下文動態變化：原始碼模式、表格、公式、程式碼區塊、標題分別顯示對應操作。
- 「更新內容」改為在新視窗以唯讀方式開啟，不再覆蓋目前文件，也不會被誤編輯或觸發儲存提示。
- 匯出 HTML/PDF 支援數學公式渲染（自包含 KaTeX CSS 與字型，僅打包 woff2 縮小體積）。

### 修復與改進

- 修復原始碼模式下 I 型插入游標不可見的問題。
- 純文字（.txt）文件固定使用原始碼模式，「檢視 > 原始碼模式」選單項目置灰。
- 修復選單列「插入表格 > 自訂表格」彈窗閃退；「列數/欄數」標籤與輸入框對齊。
- 側邊欄搜尋框高度略微加高。
- 復原視窗的「全部丟棄 / 丟棄所選」按鈕恢復為系統預設白色按鈕樣式。
- 匯出 PDF 改為透過系統列印面板完成：可在面板中完整調整紙張、方向與頁邊距，再儲存為 PDF。

### 更改

- 印刷排版響應「最大寬度」限制；PDF 匯出表格寬度隨內容變化。

## 1.1.7 — 2026-08-13

- 工作區側邊欄支援依檔名與內容搜尋 Markdown/TXT 文件，大綱支援依標題篩選。
- 段落左側控制鈕顯示目前區塊格式，並提供段落操作選單與段前/段後插入行。
- 待辦清單核取方塊對齊並使用主題強調色，日文列印排版使用 Yu Mincho/Yu Gothic。

## 1.1.6 — 2026-08-12

- 支援設定從外部開啟的檔案使用新視窗或目前視窗；已開啟的檔案會直接啟用對應視窗，不會重複開啟。
- 關閉、取代或結束時，對已修改的文件提示儲存、不儲存/刪除或取消；僅在對應設定開啟且寫入成功後自動儲存。
- 在「格式」選單與編輯器右鍵選單新增一次性「格式刷」。
- 提供簡體中文、繁體中文、英文與日文四種語言的 Markdown 更新日誌。
- 完整中文化復原對話框。
- 「大綱」的字型大小與灰色選取背景和「工作區」保持一致。
- 修正「大綱」第一次點按即可顯示選取背景。
- 切換語言後保留偏好設定的目前頁面與視窗位置。

## 1.1.5 — 2026-08-12

- 新增「漢字優先字型」，支援簡體、繁體、日文與韓文字形偏好。
- 檢視選單新增「專注模式」，F11 進入、Esc 結束。
- 編輯器字型選項合併至獨立「字型設定」對話框。
- 襯線與無襯線樣式新增思源/Noto CJK 字型回退。
- 大綱字型大小與灰色選取陰影與 Workspace 保持一致。
- 更新莫蘭迪主題的頁面背景色。

- 左側工作區支援應用程式內拖曳移動，以及拖到 Finder 複製。
- 還原側欄展開狀態與使用中的頁籤。

- 切換語言後原生介面立即重新整理。
