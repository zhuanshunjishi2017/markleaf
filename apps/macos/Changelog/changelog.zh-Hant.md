# MarkLeaf 更新內容

## 1.3.2 — 2026-08-23

- 修復側欄隱藏時拖曳視窗左側調整大小會意外重新顯示側欄的問題。
- 修復隱藏側欄啟動後首次顯示側欄時，側欄先閃現完整寬度再重新展開，以及狀態列按鈕意外取得焦點的問題。
- 修復格式刷從右向左選取整行或連續選取多個段落時，選取範圍已顯示但格式未套用、格式刷仍保持啟用的問題。

## 1.3.1 — 2026-08-22

- 新增「編碼」相關設定：「偏好設定」支援設定「新檔案預設編碼」，「狀態列」支援即時調整目前文件的編碼方式，並支援以最合適的編碼開啟檔案。

- 微調「偏好設定」的視窗配置。
- 狀態列「視覺化」現已改為模式選單。

- 「關於」畫面的版本號現以「版本號 + 組建號」顯示。
- 修復「關於」畫面的組建號固定為 42 的問題：現在會讀取執行中應用程式套件的真實版本資訊，建置指令碼預設以 Git 提交數產生組建號。
- 縮放時現在可保持目前視窗中的文件位置。
- 「關於」視窗現在會在目前螢幕中央上方顯示，並採用更緊湊的配置，補充完整 GitHub 連結與版權資訊，並改善版權列的顏色和間距。

- 將「漢字優先字型」移至「字型設定」。
- 「偏好設定」現在為簡體中文、繁體中文、英文與日文使用各自穩定的視窗寬度；切換頁面時只調整高度，並修復英文與日文長標籤被遮擋的問題。
- 啟用「自動隱藏捲動軸」時，捲動軸會平順淡入淡出；系統啟用「減少動態效果」時會自動取消動畫。
- 統一「格式」與「段落」選單的可用性邏輯：未選取文字時停用粗體、斜體、底線和刪除線；行內程式碼可透過輸入視窗直接插入；段落命令統一作用於目前段落或選取範圍涵蓋的段落。
- 將選單列和快速鍵設定中的「尋找」與「取代」合併為「尋找與取代」，沿用 ⌘F 作為預設快速鍵；並可在同一視窗中平順展開或收合取代功能。

- 插入段間公式、行內程式碼與插入註釋視窗的文字框現採用與「偏好設定」一致的細圓角矩形樣式，並縮短段間公式編號與輸入框之間的距離；註釋編號支援以 Esc 復原目前輸入，並在焦點離開時立即驗證。
- 修復選取已算繪的 LaTeX 公式時會連帶選取前方文字的問題。

- 修復未選取文字時「拷貝」與「複製為」仍可使用的問題。
- 修復「尋找與取代」視窗中的文字框無法使用系統快捷鍵的問題。

- 修復已開啟工作區後，透過側欄按鈕選擇另一個資料夾時應用程式崩潰的問題。
- 修復隱藏側欄啟動後首次顯示時，「尚未開啟工作區」錯位、「開啟資料夾」按鈕消失及側欄寬度異常的問題。

- 修復側欄隱藏時，開啟檔案或執行儲存會意外重新顯示側欄的問題。

## 1.3.0 — 2026-08-20

### 新增

- 搜尋結果顯示資料夾圖示與關鍵字附近的上下文；點擊結果後會離開搜尋並在工作區樹狀目錄中展開、選取目標檔案。
- 狀態列支援自訂：可分別顯示/隱藏側欄切換按鈕、命令狀態、字數、區塊類型、游標位置、編碼、換行符、原始碼/視覺化切換與縮放比例。
- 狀態列字數可點擊，開啟詳細文件統計（字數、已選字數、總字數、非空白字數、CJK 字數、西文單字數、公式數、程式碼行數、段落數與行列位置）。
- 工作區右鍵選單補齊新增檔案、新增資料夾、複製路徑、在 Finder 中顯示、在新視窗開啟、重新命名、刪除、樹狀/清單切換、排序、重新整理與關閉工作區。
- 文件清單模式顯示所在資料夾與修改時間，支援依檔案名稱或修改時間排序，並可切換遞增/遞減。
- 支援從 Finder 拖入 .md/.txt/.markdown 檔案到工作區，自動複製到目標目錄。
- 工作區樹支援按 Return 開啟檔案，或在資料夾上展開/收合。
- 圖片右鍵選單與格式選單補齊更換圖片、調整大小（100%/75%/90%/50%）、順時針旋轉與圖片另存為。
- 檔案選單新增「以唯讀方式開啟」。
- 段落選單新增「清除段落格式」。
- 偏好設定「外觀」新增「自動隱藏捲動軸」開關。

### 更改

- 首次啟動不再自動接管 Markdown/純文字檔案關聯；只有使用者主動啟用後，MarkLeaf 才會成為預設編輯器。
- 狀態列命令回饋與文件狀態拆分為獨立欄位，不再互相覆蓋；「暫時顯示」模式會在 5 秒後自動清空。
- 自訂狀態列視窗改為緊湊配置，標題、選項與命令狀態顯示方式使用一致的對齊與間距。
- PDF 與 HTML 共用一個「匯出…」視窗；檔案選單只保留一個匯出入口，並繼續提供「依上次設定匯出」。
- 匯出視窗預設使用目前排版樣式與配色主題，預設頁邊距改為「標準」；仍可為單次匯出選擇其他配色，依上次設定匯出時則保留歷史配色。
- 搜尋可真正取消，停止繼續走訪目錄與讀取檔案。

### 修復

- 修復點擊搜尋結果後偶爾無法在工作區樹狀目錄中定位目標檔案的問題。
- 修復工作區右鍵選單缺少新增、重新命名、刪除、排序等操作的問題。
- 修復從 Finder 拖入檔案到工作區被拒絕的問題。
- 修復文件清單資訊不足且無法排序的問題。
- 修復取消搜尋後仍繼續讀取檔案、佔用磁碟與 CPU 的問題。
- 修復狀態列缺少編碼、換行符、原始碼/視覺化切換、縮放等欄位且無法自訂的問題。
- 修復自訂狀態列視窗左側留白過大、標題未對齊及下拉選單距離過遠的問題。
- 修復檔案選單重複顯示舊「匯出為」子選單的問題。
- 修復匯出視窗忽略目前主題、預設使用歷史深色配色，以及預設頁邊距顯示為「自訂」的問題。
- 修復唯讀模式下 ⌘A 全選、⌘C 複製快捷鍵無效，以及選區無法用 Esc 或失焦取消、高亮殘留的問題。

## 1.2.6 — 2026-08-19

### 新增

- 匯出視窗底部新增「依上次設定匯出」按鈕，可直接沿用上次的匯出設定。
- 頁首/頁尾的自訂文字框改為圓角樣式，僅在預設選擇「自訂」時顯示在對應下拉框下方，其他選項自動下移並帶平滑動畫。
- 編輯選單與右鍵選單的剪貼板指令統一為剪下、拷貝、貼上、貼上為純文字和「複製為」，並依是否有選取文字、剪貼板內容與唯讀狀態自動置灰。
- 新增腳註支援：`[^x]` 顯示為上標引用，`[^x]:` 段落顯示為腳註定義；匯出 HTML/PDF 時產生專用結構。
- 段落選單新增「插入註釋」指令，可填寫註釋編號與註釋文字，在目前位置插入引用並在文末加入定義。
- 按住 ⌃ 鍵點擊腳註引用可跳至對應定義；定義缺失時會明確提示。
- 腳註定義段落右鍵選單新增「重設註釋編號」，可批次替換相同編號的引用與定義。

### 修復

- 修復隱藏側邊欄時開啟新檔案會重複播放收合動畫的問題。
- 修復深色主題匯出 PDF 時僅正文區域為深色、頁邊距區域仍為白色的問題。
- 修復匯出預覽重新產生時頁面閃爍、總頁數文字消失又出現的問題。

## 1.2.5 — 2026-08-19

### 新增

- 原始碼模式支援復原、重做，並統一以純文字方式處理貼上內容。
- 新增「貼上為純文字」（`⌘⇧V`），並將複製選單統一為「複製/貼上為」。
- 原始碼模式支援偵測不符合 CommonMark 規則的閉合星號標記，可選擇保留字面值或轉為 HTML 標籤；提示視窗支援「不再提示」與「了解詳情」。
- 產生 Markdown 時自動偵測粗體、斜體標記的危險邊界，必要時轉為 HTML 標籤，避免重新載入後暴露星號原始碼。
- 唯讀模式使用受限的系統右鍵選單，並停用原始碼模式編輯操作。
- 合併 HTML 與 PDF 匯出視窗，並新增「依上次設定匯出」。
- 匯出設定會持久化儲存；PDF 匯出支援頁首頁尾、文件標題/頁碼/總頁數佔位符及自訂內容。
- 新增淺色「檸檬海鹽（saltlemon）」配色方案。

### 更改

- 基礎排版自適應邊距刪除最小一檔，並適度減小左右邊距；匯出視窗預設同步目前排版樣式與配色。
- PDF 頁首頁尾使用所選排版樣式字型，字號為正文標準字號的 0.875，上下間距調整為 6mm。
- PDF 匯出移除正文容器的最大寬度限制，使表格可擴展至頁邊距範圍；自訂邊距修改後自動切換至自訂檔位。
- 關閉最後一個編輯視窗後，MarkLeaf 繼續駐留在 Dock；點擊 Dock 圖示時恢復既有視窗，或建立新的空白視窗。

### 修復

- 修復原始碼模式貼上 HTML/富文本內容為空、純文字貼上後游標位置異常後移的問題。
- 修復視覺化模式輸入全形符號、全形字母、全形數字時游標異常跳動的問題。
- 修復複製圖片後再次貼上變為空白或僅保留圖片標題文字的問題。
- 修復跟隨系統顏色模式點擊確定後主題不會立即套用的問題。
- 修復唯讀模式仍可能彈出前端編輯選單或回應編輯操作的問題。
- 修復 PDF 頁首頁尾字型未依目前排版樣式渲染，以及表格無法填滿可用寬度的問題。
- 調整 macOS Dock 圖示的安全邊距，使 MarkLeaf 與相鄰應用程式的視覺大小一致。

## 1.2.4 — 2026-08-17

### 新增

- 修復表格/圖片標題在編輯器與匯出中顏色、字型大小不一致的問題。

- 右鍵選單依上下文動態變化：原始碼模式、表格、公式、程式碼區塊、標題分別顯示對應操作。

- 匯出 HTML/PDF 支援數學公式渲染（自包含 KaTeX CSS 與字型，僅打包 woff2 縮小體積）。

### 修復與改進

- 修復原始碼模式下 I 型插入游標不可見的問題。
- 純文字（.txt）文件固定使用原始碼模式，「檢視 > 原始碼模式」選單項目置灰。
- 修復選單列「插入表格 > 自訂表格」彈窗閃退；「列數/欄數」標籤與輸入框對齊。
- 側邊欄搜尋框高度略微加高。
- 復原視窗的「全部丟棄 / 丟棄所選」按鈕恢復為系統預設白色按鈕樣式。
- 匯出 PDF 改為透過系統列印面板完成：可在面板中完整調整紙張、方向與頁邊距，再儲存為 PDF。

### 更改

- 印刷排版響應「最大寬度」限制；PDF 匯出表格寬度隨內容變化。
