# MarkLeaf 更新内容

## 1.7.8 — 2026-10-10

### 修复

- 修复侧边栏滚动条无法自动隐藏的问题。
- 修复源码模式下大纲跳转部分标题或段落定位不准确的问题。

## 1.7.7 — 2026-10-8

### 新增

- 新增 Quick Look 预览扩展，支持在 Finder 中预览 Markdown、Markdown 变体和纯文本文件。
- 新增「只读模式」，可在可视化与源码模式下阻止编辑操作。
- 新增稳定阅读锚点，编辑、切换模式或重新打开文档后，阅读位置定位更稳定。
- 新增可选外部代码格式化器，支持格式化整个代码块和已选代码片段。
- 新增 SQL 方言设置，支持在偏好设置中显式选择 SQL 格式化方言。
- 新增「启动时自动检查更新」，启动后静默检查新版本。
- 恢复未保存文件窗口新增「打开」选项，可直接继续编辑而无需立即保存。
- 代码块支持使用 `Tab` / `Shift+Tab` 增加和减少缩进。
- Markdown 行为设置新增「代码块拼写检查」选项，默认关闭。
- 「清除历史记录」等破坏性操作前新增确认提醒。

### 更改

- 为 macOS 26/27 进一步适配 Liquid Glass，覆盖标题栏、侧边栏、标签栏、状态栏和部分浮动窗口。
- 侧边栏切换、搜索框和过滤控件改用更原生的 Liquid Glass 样式，并优化垂直对齐与可用状态。
- 优化编辑器标签栏外观，选中标签使用更清晰的胶囊样式。
- 统一侧边栏、浮动窗口和编辑器的滚动条宽度与 overlay 样式。
- 关闭「与操作系统同步」时保留当前正在显示的颜色主题，后续手动切换主题时立即生效。
- 关闭多标签页模式时，禁用依赖新标签页的选项，并回退不兼容的文件打开方式。
- 可视化排版设置拆分为独立轻量窗口，并优化字体设置、外观设置和输入框对齐。
- 偏好设置中部分编辑器选项重新分组，布局更整齐。
- 优化复制语义，选区导出更完整地保留任务列表、脚注引用、脚注定义和表格单元格选区。
- 补齐声明代码语言预设和外部格式化器语言的代码高亮，并统一两者的显示顺序。
- 源码模式支持章节检测与章节跳转。
- 优化拖选高亮性能，减少长文档和大量选区下的卡顿。
- 优化超大 Markdown 文档打开性能，减少解析阶段的全量扫描和块级公式宽度测量造成的主线程卡顿。

### 修复

- 修复首次启动或切换深浅模式时，标题栏、侧边栏、状态栏和部分控件颜色更新不及时的问题。
- 修复颜色主题手动选择后被旧主题覆盖的问题。
- 修复「与操作系统同步」开启时，置灰的颜色主题未显示当前实际主题的问题。
- 修复标签页数量较多时，溢出菜单箭头无法点击的问题。
- 修复侧边栏隐藏再显示后，部分状态信息丢失或闪烁的问题。
- 修复侧边栏搜索框垂直对齐异常、点击不可搜索的问题。
- 修复未打开工作区时，工作区搜索框仍误判为可用的问题。
- 修复启动时标题栏 MarkLeaf 或文件名偶发偏离中心并跳动的问题。
- 修复从 Finder 拖入 Markdown 或纯文本文件时无法打开的问题。
- 修复没有打开任何标签页时，从「最近项目」打开已不存在的文档不会提示错误，且后续新建标签页出现无效文档的问题。
- 修复长文档拖选、Shift+方向键选择或接近窗口边缘自动滚动时，高亮不稳定、整行误高亮或无法取消选中的问题。
- 修复表格多选单元格时复制仍只复制当前单元格的问题。
- 修复表格拖选时文字选区与整格选区互相切换导致高亮闪烁的问题。
- 修复表格跨格选区后打开右键菜单、再点击其他位置关闭菜单时，选区高亮残留且持续闪烁、无法通过点击取消的问题。
- 修复点击段间公式时，编辑器出现带桌面背景色调的大面积异常高亮的问题。
- 修复在已拖选内容上点击右键时，选区被收缩到点击位置的问题。
- 修复开启中西文自动空格后，在文字边界拖选时短暂误高亮前文的问题。
- 修复部分标题或段落定位不准确的问题，提升阅读位置恢复的可靠性。
- 修复拖选一段文字后直接输入无法替换选中内容的问题。
- 修复多标签页下，状态栏切换源码模式、调整缩放、换行符与编码等操作被发送到隐藏的初始标签而失效的问题。

## 1.7.6 — 2026-09-12

### 新增

- 「文件」菜单新增「重命名」，可用于当前打开的本地文件。
- 新增非多标签页模式下，标题栏的修改状态动画。
- 新增非多标签页模式下，只读文件会在标题栏显示「只读」。

### 更改

- 工作区树、列表和搜索现在统一为 `.md` / `.txt`，预览和搜索采用一致的 HTML 标签间隔与实体解码。
- 「复制 HTML」现在会复制源码文本，普通格式化复制继续提供文本和 HTML。
- 树形与文档列表扫描现在独立执行，切换或关闭工作区后不再接收已取消扫描的旧结果。
- 当前文件未修改或已保存时，「保存」和「保存全部」现在会自动禁用。
- 标签页右键菜单移除文件操作项，相关操作集中保留在「文件」菜单中。
- 调整了菜单栏中部分选项的位置。
- 微调了英文模式下「偏好设置」窗口的布局。

### 修复

- 修复只含 PDF、图片或压缩包等非文本文件的目录展开后循环刷新的问题。
- 修复旧网页查找栏引用导致编辑器启动中断、编辑区空白的问题。
- 修复恢复上次会话的窗口未绑定文件打开及对话框宿主，导致选择文件后没有加载的问题。
- 修复导出 PDF 时，部分标题无法定位到 PDF 文本导致导出界面闪退的问题。
- 修复深色模式下启动应用、重启编辑器或新建标签页时，编辑区可能闪白的问题。
- 修复切换深浅主题后，标题栏、标签栏和状态栏未同步更新的问题。
- 修复源码模式下“自动隐藏滚动条”不生效的问题。
- 修复大纲点击无法定位到对应标题的问题。
- 修复“在右侧显示大纲”开启时菜单仍显示为未勾选的问题。
- 修复「外部文件打开方式」为「在当前标签页中打开」时，外部打开、「打开…」和最近项目仍可能新建标签页的问题。
- 修复长文档拖选或 Shift+方向键选择时列表整行误高亮，以及拖选到窗口边缘无法自动滚动的问题。
- 修复撤销到已保存内容后仍显示「已修改」的问题。
- 修复只读文件仍可通过「文件」菜单重命名的问题。
- 修复在代码块、行内代码、YAML Front Matter 或脚注定义中粘贴时，内容逃出当前容器的问题。
- 修复从 Finder 等外部来源拖入图片无法插入文档的问题。

## 1.7.5 — 2026-09-10

### 新增

- 新增「多标签页功能」。
- 新增「完整会话恢复」功能，下次启动可恢复上次的窗口、标签、光标与滚动位置。
- 文件菜单新增「在工作区定位」「复制文件路径」「复制内容到剪贴板」「在 Finder 中显示」「分享」，更易于文件操作。
- 代码块右上角新增「复制」与「语言」控件。
- 新增 YAML 前置元数据支持与格式校验，并提供基础、进阶示例文档。
- 新增公式浮层编辑与公式编号，支持 `\(...\)` 行内公式和 `\[...\]` 行间公式的识别、渲染与导出。
- Mermaid 支持 default / dark / neutral 三套主题，切换主题或排版样式后自动重新渲染。
- 新增「Markdown 行为」设置窗口：可配置转义行为、空行回车退出块、Shift+Enter 硬换行、代码围栏、强调标记与列表标记。
- 新增「无视最大宽度限制」「显示代码高亮」等偏好设置；文档内的本地链接可直接打开对应文件。
- 侧栏新增工作区文件预览与全文搜索。
- 新增「外部文件打开方式」与「工作区文件打开方式」偏好，重复打开文件时自动去重。
- 支持在侧栏重命名、移动文件与文件夹，已打开的标签会同步迁移路径。
- 新增「导出」功能「不允许标题处于页面最底部」「不允许表格分居两页」等分页选项。
- 新增统一的「主题设置…」窗口：颜色主题与排版样式分页，颜色主题按浅色/深色分组并显示预览色块，支持跟随系统颜色、默认浅色/深色主题、添加主题与打开主题文件夹。
- 新增「安装可选字体…」窗口；排版样式缺字体时显示提示与「缺字体」徽标。

### 更改

- 菜单栏按文件 / 编辑 / 插入 / 格式 / 视图 / 帮助重新规划。
- 编辑器右键菜单现在按功能重新分组，并显示用户自定义快捷键。
- 导出 HTML / PDF 时现在可把本地图片内嵌到文件中，长图导出自动切片。
- 「格式 → 代码块」现在支持自定义标识符。
- 「编辑器专注模式」按视口比例淡化非当前段落；「打字机模式」按视口约 42% 保持光标位置，短文档不再强制滚动。
- 编辑器滚动位置会随标签切换与模式切换保留。
- 内置主题标识符统一迁移，旧的主题设置会自动对应到新主题。
- 加宽工作区侧栏并调整行内信息密度：文件名优先显示，时间格式更紧凑。
- 「导出」功能现在支持导出为图片。

### 修复

- 修复「最简模式」勾选后菜单仍显示为未勾选的问题。
- 修复源码模式下「编辑器专注模式」「打字机模式」以及可视化的插入、格式命令仍可执行的问题。
- 修复编辑器右键菜单缺少撤销、重做、全选，且命令不显示快捷键的问题。
- 修复源码模式下子菜单父项（图片、插入表格、Mermaid、段落操作、段落样式、列表、提示框）未整体置灰的问题。
- 修复文档为空时「复制内容到剪贴板」仍可点击的问题；文件菜单、标签页右键菜单与工作区文件右键菜单现在行为一致。
- 修复关闭所有标签后窗口被一并关闭、状态栏残留文档信息的问题。
- 修复标签拖拽过程中抬起与落位异常、动画重复播放的问题。
- 修复侧栏空状态、标签选中态，以及暗色主题下侧栏展开闪烁的问题。
- 修复下划线与字面加号冲突导致的文字损坏：`C++17`、`i++`、`++i` 等内容在编辑和重新打开后不再被改写或吞字。
- 修复段间公式被过早转换为行内公式，以及公式前后的数字文本被误判的问题。
- 修复 Mermaid 字体测量导致的渲染与排版抖动。
- 修复导出预览未跟随当前标签切换，以及图片导出布局与校验的问题。
- 修复关闭「段落块句柄」后启动应用时，编辑区偶发闪现操作柄的问题。
- 修复关闭「显示代码高亮」后打开文档时，代码块先以高亮样式绘制再恢复的问题。
