# MarkLeaf 更新内容

## 1.3.1 — 2026-08-22

- 新增「编码」相关设置：「偏好设置」支持设置「新建文件默认编码」，「状态栏」支持即时调整当前文档编码方式，支持使用最合适的编码打开文件。

- 微调了「偏好设置」的窗口布局。
- 状态栏「可视化」现在更改为模式菜单。

- 「关于」界面版本号现在使用 `版本号 + 构建号` 的方式显示。
- 修复「关于」界面的构建号被固定为 42 的问题：现在读取运行中应用包的真实版本信息，构建脚本默认使用 Git 提交计数生成构建号。
- 缩放时现在可以保持当前视口中的文档位置。
- 「关于」窗口现在会在当前屏幕中央上方显示，并采用更紧凑的布局，补充完整 GitHub 链接与版权信息，优化版权行的颜色和间距。

- 将「汉字优先字型」移入「字体设置」。
- 「偏好设置」现在为简体中文、繁体中文、英语和日语使用独立且稳定的窗口宽度；切换页面时仅调整高度，并修复英、日文长标签被遮挡的问题。
- 启用「自动隐藏滚动条」时，滚动条会平滑淡入淡出；系统启用「减少动态效果」时自动取消动画。
- 统一「格式」与「段落」菜单的可用性逻辑：未选择文本时禁用加粗、斜体、下划线和删除线；行内代码可通过输入窗口直接插入；段落命令统一作用于当前段落或选区覆盖的段落。
- 将菜单栏和快捷键设置中的「查找」与「替换」合并为「查找与替换」，沿用 ⌘F 作为默认快捷键；替换功能可在同一窗口中平滑展开或收起。

- 插入段间公式、行内代码与插入注释窗口的文本框现在使用与「偏好设置」一致的细圆角矩形样式，并收紧段间公式编号与输入框之间的间距；注释编号支持 Esc 撤销当前输入，并在焦点离开时立即校验。
- 修复选择已渲染的 LaTeX 公式时连带选中前方文本的问题。

- 修复未选择文本时「拷贝」与「复制为」仍可用的问题。
- 修复「查找与替换」窗口中文本框无法使用系统快捷键的问题。

- 修复已打开工作区后通过侧栏按钮选择另一个文件夹时应用崩溃的问题。
- 修复隐藏侧边栏启动后首次显示时，「暂未打开工作区」错位、「打开文件夹」按钮消失及侧栏宽度异常的问题。

- 修复侧边栏隐藏时，打开文件或执行保存会意外重新显示侧边栏的问题。

## 1.3.0 — 2026-08-20

### 新增

- 新增「自定义状态栏」，支持自定义显示在状态栏的字段。
- 新增「文档统计」功能，支持统计当前文档字数、已选字符数、总字符数等信息。

- 支持从 Finder 拖入 .md/.txt/.markdown 文件到工作区，自动复制到目标目录。

- 图片右键菜单与格式菜单新增「更换图片」、「调整大小」（100%/75%/90%/50%）、「顺时针旋转」与「图片另存为」。
- 文件菜单新增「以只读方式打开」。
- 段落菜单新增「清除段落格式」。
- 偏好设置「外观」新增「自动隐藏滚动条」开关。

### 更改

- 「搜索」功能的搜索结果现在支持显示关键词附近的上下文，点击结果后支持在文件树中进行定位。
- 首次启动 MarkLeaf 后，应用不再自动接管 Markdown/纯文本文件关联。
- 「状态栏」命令反馈与文档状态拆分为独立字段，不再互相覆盖。
- 「文档列表模式」现在支持显示文档的修改时间。

- 「导出」窗口默认页边距现在改为「标准」。

### 修复

- 修复点击搜索结果后偶尔无法在工作区树中定位目标文件的问题。
- 修复工作区右键菜单缺少新建、重命名、删除、排序等操作的问题。
- 修复从 Finder 拖入文件到工作区被拒绝的问题。
- 修复文档列表信息不足且无法排序的问题。
- 修复取消搜索后系统仍继续遍历目录和读取文件，占用磁盘与 CPU 的问题。

- 修复「只读模式」下全选、复制快捷键无效，以及选区无法用 Esc 或失焦取消、高亮残留的问题。

## 1.2.6 — 2026-08-19

- 「导出」窗口新增「按上次设置导出」按钮，支持沿用上次的导出设置。

- 调整了编辑菜单与右键菜单的剪贴板命令。
- 新增「脚注」功能，`[^x]` 显示为上标引用，`[^x]:` 段落显示为脚注定义。
- 新增「段落」菜单「插入注释」命令，支持填写注释编号与注释文本。

- 修复隐藏侧边栏时打开新文件会重复播放收起动画的问题。
- 修复深色主题导出 PDF 时仅正文区域为深色、页边距区域仍为白色的问题。
- 修复导出预览重新生成时页面闪烁、总页数提示反复消失的问题。

## 1.2.5 — 2026-08-19

### 新增

- 「源码模式」现在支持撤销、重做，并统一以纯文本方式处理内容。
- 新增「粘贴为纯文本」命令。
- 源码模式支持检测不符合 CommonMark 规则的闭合星号标记，可选择保留字面量或转为 HTML 标签。

- 「只读模式」新增受限的右键菜单。

- 新增「柠檬海盐」颜色主题。

### 更改

- 删除基础排版自适应边距最小一档，并适当减小了左右边距。
- 「导出」窗口现在会默认同步当前排版样式和配色。
- 「导出」功能中的设置现在可以持久化保存。
- 导出为 PDF 时，页眉页脚现在会使用所选排版样式字体，字号为正文标准字号的 0.875，上下间距为 6mm。

- 关闭所有编辑窗口后，MarkLeaf 现在支持继续驻留在 Dock。
- 调整了应用 Dock 图标的安全边距。

### 修复

- 修复「源码模式」下粘贴 HTML/富文本内容为空、纯文本粘贴后光标位置异常后移的问题。
- 修复「可视化模式」下输入全角符号、全角字母、全角数字时光标异常跳动的问题。
- 修复复制图片后再次粘贴变为空白或仅保留图片标题文本的问题。
- 修复选中颜色主题「与操作系统同步」时主题不会立即应用的问题。
- 修复「只读模式」下仍可能弹出前端编辑菜单或响应编辑操作的问题。

## 1.2.4 — 2026-08-17

- 「段间公式」现在支持进行编号。

- 新增「打印」功能。
- 新增「自定义快捷键」功能。

- 修复专注模式默认快捷键 F11 与系统冲突的问题。

- 修复「字体设置」窗口过大的问题。
- 修复段落菜单中无序列表、有序列表、任务列表无法应用格式的问题。
- 修复标题菜单项相关文案显示错误的问题。
- 修复列表项不显示段落块句柄、格式刷无法用于列表的问题。
- 修复在「打印」窗口中点击“取消”后应用闪退的问题。
- 修复源码模式下关闭侧边栏后行号与正文间隔过大的问题。

## 1.2.0 — 2026-08-14

- 新增 LaTeX 数学公式支持，自动渲染行内公式 `$...$` 与块级公式 `$$...$$`。
- 新增段落菜单「段间公式」、格式菜单「行内公式」命令。
- 新增公式右键菜单。

- 修复源码模式下光标不可见的问题。

- PDF 导出表格宽度现在可以随内容变化。
- 右键菜单现在可以按上下文动态变化，分别显示对应操作。
- 「更新内容」现在会以只读方式打开。
- 略微加高了侧边栏搜索框的高度。
- 「导出为PDF」功能现在通过系统打印面板完成。
- 现在纯文本文档固定使用「源码模式」打开。

## 1.1.7 — 2026-08-13

- 新增「搜索」功能，支持按文件名和内容搜索文档，大纲支持按标题过滤。
- 新增「段落块句柄」，支持显示当前块格式，并提供段落操作菜单。

## 1.1.6 — 2026-08-12

- 新增「外部文件打开方式」，允许外部打开的文件使用新窗口或当前窗口。
- 在文件关闭、替换或退出时，新增「保存已修改的文档」的提示。
- 新增「格式刷」功能。
- 现在「更新内容」使用 Markdown 进行排版。
- 修复有关崩溃恢复的若干问题。

- 现在切换语言后可以保留偏好设置的当前页面和窗口位置。

## 1.1.5 — 2026-08-12

- 新增「专注模式」。

- 衬线和无衬线样式现在支持回退到「思源/Noto CJK」 字体。
- 修复大纲字号和灰色选中阴影与 Workspace 不一致的问题。
- 新增「莫兰迪」系列颜色主题。

## 1.1.4 — 2026-08-11

- 现在支持为浅色和深色模式分别设置默认主题。

- 修复切换语言后原生界面无法即时刷新的问题。

## 1.1.3 — 2026-08-10

- 修复编辑器滚动条过粗且颜色不随主题变化的问题。
- 修复深色模式下编辑器加载完成时会出现白色闪烁的问题。
- 现在应用退出时会自动清理 7 天前的日志。
- 新增「更新内容」菜单。
