# MarkLeaf 更新内容

## 1.3.1 — 2026-08-21

### 新增

- 状态栏换行符改为带勾选状态的菜单，可为当前已打开文件切换 LF/CRLF 并在保存时写入；偏好设置「文本格式」可设置新建文件默认换行符。
- 状态栏「可视化」改为带勾选状态的模式菜单，可明确选择可视化或源码模式。
- 状态栏与偏好设置支持选择 UTF-8、UTF-8 with BOM、US-ASCII、UTF-16、UTF-16 with BOM、GB2312、GBK、GB18030、Big5 和 Shift_JIS。
- 打开文件时自动识别 UTF-8/UTF-16 BOM；切换编码可能导致乱码时显示警告，并在保存时避免不可表示字符被静默丢失。
- 打开无 BOM 文件时会对有效 UTF-8、UTF-16 以及中文/日文编码候选进行可逆性和乱码特征评分，自动选择更合适的编码。

### 更改

- 偏好设置窗口改为更紧凑的居中布局，重新调整底部操作区间距、说明文案缩进以及「文件」页面的视觉重心。
- 从隐藏侧边栏状态启动后的首次展开动画与后续展开/收起动画统一，并从真实的零宽状态开始。
- 移除重复的「UTF-8 without BOM」和「UTF-16 without BOM」选项；无 BOM 编码分别统一显示为「UTF-8」和「UTF-16」。

### 修复

- 修复未选择文本时「拷贝」与「复制为」仍可用的问题，编辑和只读模式现在都会正确置灰。
- 修复查找与替换文本框无法使用 ⌘V 等系统剪贴板快捷键，以及右键菜单在第二次打开后变窄、折叠选项的问题。
- 修复工作区中单击文件后选中高亮只闪现一下、必须双击才会保持的问题。
- 修复已打开工作区后通过侧栏按钮选择另一个文件夹时应用崩溃的问题。
- 修复隐藏侧边栏启动后首次显示时，「暂未打开工作区」错位、打开文件夹按钮消失及侧栏宽度异常的问题。
- 修复首次显示侧边栏的动画起始宽度和节奏与正常展开动画不一致的问题。
- 修复侧边栏隐藏时，打开文件或执行保存会意外重新显示侧边栏的问题。
- 兼容旧版本保存的 UTF-8/UTF-16 无 BOM 设置，升级后自动迁移到新的选项名称。

## 1.3.0 — 2026-08-20

### 新增

- 搜索结果显示文件夹图标与关键词附近的上下文；点击结果后会退出搜索并在工作区树中展开、选中目标文件。
- 状态栏支持自定义：可分别显示/隐藏侧栏切换按钮、命令状态、字符数、块类型、光标位置、编码、换行符、源码/可视化切换与缩放比例。
- 状态栏字符数可点击，打开详细文档统计（字数、已选字符数、总字符数、非空白字符数、CJK 字符数、西文单词数、公式数、代码行数、段落数与行列位置）。
- 工作区右键菜单补齐新建文件、新建文件夹、复制路径、在 Finder 中显示、在新窗口打开、重命名、删除、树/列表切换、排序、刷新与关闭工作区。
- 文档列表模式显示所在文件夹与修改时间，支持按文件名或修改时间排序，并可切换升序/降序。
- 支持从 Finder 拖入 .md/.txt/.markdown 文件到工作区，自动复制到目标目录。
- 工作区树支持按 Return 打开文件，或在文件夹上展开/收起。
- 图片右键菜单与格式菜单补齐更换图片、调整大小（100%/75%/90%/50%）、顺时针旋转与图片另存为。
- 文件菜单新增「以只读方式打开」。
- 段落菜单新增「清除段落格式」。
- 偏好设置「外观」新增「自动隐藏滚动条」开关。

### 更改

- 首次启动不再自动接管 Markdown/纯文本文件关联；只有用户主动启用后，MarkLeaf 才会成为默认编辑器。
- 状态栏命令反馈与文档状态拆分为独立字段，不再互相覆盖；「临时显示」模式会在 5 秒后自动清空。
- 自定义状态栏窗口改为紧凑布局，标题、选项与命令状态显示方式使用统一对齐和间距。
- PDF 与 HTML 共用一个「导出…」窗口；文件菜单只保留一个导出入口，同时继续提供「按上次设置导出」。
- 导出窗口默认使用当前排版样式和配色主题，默认页边距改为「标准」；仍可为单次导出选择其他配色，按上次设置导出时保留历史配色。
- 搜索支持真正取消，停止继续遍历目录和读取文件。

### 修复

- 修复点击搜索结果后偶尔无法在工作区树中定位目标文件的问题。
- 修复工作区右键菜单缺少新建、重命名、删除、排序等操作的问题。
- 修复从 Finder 拖入文件到工作区被拒绝的问题。
- 修复文档列表信息不足且无法排序的问题。
- 修复取消搜索后仍继续读取文件、占用磁盘与 CPU 的问题。
- 修复状态栏缺少编码、换行符、源码/可视化切换、缩放等字段且无法自定义的问题。
- 修复自定义状态栏窗口左侧留白过大、标题未对齐以及下拉框距离过远的问题。
- 修复文件菜单重复显示旧「导出为」子菜单的问题。
- 修复导出窗口忽略当前主题、默认使用历史深色配色，以及默认页边距显示为「自定义」的问题。
- 修复只读模式下 ⌘A 全选、⌘C 复制快捷键无效，以及选区无法用 Esc 或失焦取消、高亮残留的问题。

## 1.2.6 — 2026-08-19

### 新增

- 导出窗口底部新增「按上次设置导出」按钮，可直接沿用上次的导出设置。
- 页眉/页脚的自定义文本框改为圆角样式，仅在预设选择「自定义」时显示在对应下拉框下方，其他选项自动下移并带平滑动画。
- 编辑菜单与右键菜单的剪贴板命令统一为剪切、拷贝、粘贴、粘贴为纯文本和「复制为」，并按是否有选中文本、剪贴板内容与只读状态自动置灰。
- 新增脚注支持：`[^x]` 显示为上标引用，`[^x]:` 段落显示为脚注定义；导出 HTML/PDF 时生成专用结构。
- 段落菜单新增「插入注释」命令，可填写注释编号与注释文本，在当前位置插入引用并在文末添加定义。
- 按住 ⌃ 键点击脚注引用可跳转到对应定义；定义缺失时给出明确提示。
- 脚注定义段落右键菜单新增「重设注释编号」，可批量替换相同编号的引用与定义。

### 修复

- 修复隐藏侧边栏时打开新文件会重复播放收起动画的问题。
- 修复深色主题导出 PDF 时仅正文区域为深色、页边距区域仍为白色的问题。
- 修复导出预览重新生成时页面闪烁、总页数文案消失又出现的问题。

## 1.2.5 — 2026-08-19

### 新增

- 源码模式支持撤销、重做，并统一以纯文本方式处理粘贴内容。
- 新增“粘贴为纯文本”命令，支持 `⌘⇧V` 快捷键；复制菜单统一为“复制/粘贴为”。
- 源码模式支持检测不符合 CommonMark 规则的闭合星号标记，可选择保留字面量或转为 HTML 标签；提示窗口支持“不再提示”和“了解详情”。
- Markdown 生成时自动检测加粗、斜体标记的危险边界，必要时转为 HTML 标签，避免重新加载后暴露星号源码。
- 只读模式使用受限的系统右键菜单，并禁用源码模式编辑操作。
- 合并 HTML 与 PDF 导出窗口，并新增“按上次的设置导出”。
- 新增导出设置持久化；PDF 导出支持页眉页脚、文档标题/页码/总页数占位符，以及自定义内容。
- 新增浅色“柠檬海盐（saltlemon）”配色方案。

### 更改

- 基础排版自适应边距删除最小一档，并适当减小左右边距；导出窗口默认同步当前排版样式和配色。
- PDF 页眉页脚使用所选排版样式字体，字号为正文标准字号的 0.875，上下间距调整为 6mm。
- PDF 导出移除正文容器的最大宽度限制，使表格可扩展到页边距范围内；自定义边距修改后自动切换到自定义档位。
- 关闭最后一个编辑窗口后，MarkLeaf 继续驻留在 Dock；点击 Dock 图标时恢复已有窗口，或创建新的空白窗口。

### 修复

- 修复源码模式粘贴 HTML/富文本内容为空、纯文本粘贴后光标位置异常后移的问题。
- 修复可视化模式输入全角符号、全角字母、全角数字时光标异常跳动的问题。
- 修复复制图片后再次粘贴变为空白或仅保留图片标题文本的问题。
- 修复跟随系统颜色模式点击确定后主题不会立即应用的问题。
- 修复只读模式仍可能弹出前端编辑菜单或响应编辑操作的问题。
- 修复 PDF 页眉页脚字体未按当前排版样式渲染，以及表格无法占满可用宽度的问题。
- 调整 macOS Dock 图标的安全边距，使 MarkLeaf 与相邻应用的视觉大小一致。

## 1.2.0 — 2026-08-14

### 新增

- 支持 LaTeX 数学公式：行内 `$...$` 与块级 `$$...$$`，可视化编辑输入闭合公式后自动渲染（KaTeX）。
- 段落菜单新增“段间公式”、格式菜单新增“行内公式”命令；选中文本时直接套公式标记，未选中时弹框输入 LaTeX。
- 公式右键菜单支持编辑、行内/块级互转、删除。
- 右键菜单按上下文动态变化：源码模式、表格、公式、代码块、标题分别显示对应操作。
- “更新内容”改为在新窗口以只读方式打开，不再覆盖当前文档，也不会被误编辑或触发保存提示。
- 导出 HTML/PDF 支持数学公式渲染（自包含 KaTeX CSS 与字体，仅打包 woff2 减小体积）。

### 修复与改进

- 修复源码模式下 I 型插入光标不可见的问题。
- 纯文本（.txt）文档固定使用源码模式，“视图 > 源码模式”菜单项置灰。
- 修复菜单栏“插入表格 > 自定义表格”弹窗闪退；“行数/列数”标签与输入框对齐。
- 侧边栏搜索框高度略微加高。
- 恢复窗口的“全部丢弃 / 丢弃所选”按钮恢复为系统默认白色按钮样式。
- 导出 PDF 改为通过系统打印面板完成：可在面板中完整调整纸张、方向与页边距，再存储为 PDF。

### 更改

- 印刷排版响应“最大宽度”限制；PDF 导出表格宽度随内容变化。
