# MarkLeaf 更新内容

## 1.2.0 — 2026-08-14

### 新增

- 支持 LaTeX 数学公式：行内 `$...$` 与块级 `$$...$$`，可视化编辑输入闭合公式后自动渲染（KaTeX）。
- 段落菜单新增“段间公式”、格式菜单新增“行内公式”命令；选中文本时直接套公式标记，未选中时弹框输入 LaTeX。
- 公式右键菜单支持编辑、行内/块级互转、删除。
- 右键菜单按上下文动态变化：源码模式、表格、公式、代码块、标题分别显示对应操作。
- “更新内容”改为在新窗口以只读方式打开，不再覆盖当前文档，也不会被误编辑或触发保存提示。
- 导出 HTML/PDF 支持数学公式渲染（自包含 KaTeX CSS 与字体，仅打包 woff2 减小体积）。

### 修复与改进

- 修复源码模式下 I 型插入光标不可见的问题。
- 纯文本（.txt）文档固定使用源码模式，“视图 > 源码模式”菜单项置灰。
- 修复菜单栏“插入表格 > 自定义表格”弹窗闪退；“行数/列数”标签与输入框对齐。
- 侧边栏搜索框高度略微加高。
- 恢复窗口的“全部丢弃 / 丢弃所选”按钮恢复为系统默认白色按钮样式。
- 导出 PDF 直接保存到所选位置，不再打开系统打印面板。
- 新增“打印…”功能（⌘P）：通过系统打印面板打印当前文档，打印时强制浅色背景与深色文字。
- 专注模式快捷键由 F11 调整为 ⌘⇧F，避免与系统“显示桌面”冲突。
- “快捷键”窗口支持自定义快捷键，即时生效并持久化保存。
- 修复“快捷键”窗口初始布局异常（窗口被压缩成窄条）的问题。
- 修复“快捷键”窗口“清除”无法移除快捷键的问题。
- 修复段落菜单中无序列表、有序列表、任务列表无法应用格式的问题。
- 修复在系统打印面板中点击“取消”后应用闪退的问题。
- 修复源码模式下关闭侧边栏后行号与正文间隔过大的问题。

### 更改

- 印刷排版响应“最大宽度”限制；PDF 导出表格宽度随内容变化。

## 1.1.7 — 2026-08-13

- 工作区侧边栏支持按文件名和内容搜索 Markdown/TXT 文档，大纲支持按标题过滤。
- 段落左侧句柄显示当前块格式，并提供段落操作菜单与段前/段后插入行。
- 待办列表复选框对齐并使用主题强调色，日文打印排版使用 Yu Mincho/Yu Gothic。

## 1.1.6 — 2026-08-12

- 支持设置外部打开的文件使用新窗口或当前窗口，已打开的文件将直接激活对应窗口而不会重复打开。
- 关闭、替换或退出时，对已修改的文档提示保存、不保存/删除或取消；仅在对应设置开启且写入成功后自动保存。
- 在“格式”菜单和编辑器右键菜单新增一次性“格式刷”。
- 提供简体中文、繁体中文、英文和日文四种语言的 Markdown 更新日志。
- 完整本地化崩溃恢复对话框。
- “大纲”的字号和灰色选中背景与“工作区”保持一致。
- 修复“大纲”首次点击即可显示选中背景。
- 切换语言后保留偏好设置的当前页面和窗口位置。

## 1.1.5 — 2026-08-12

- 新增“汉字优先字型”，支持简体、繁体、日文和韩文字形偏好。
- 视图菜单新增“专注模式”，F11 进入、Esc 退出。
- 编辑器字体选项合并到独立“字体设置”对话框。
- 衬线和无衬线样式新增思源/Noto CJK 字体回退。
- 大纲字号和灰色选中阴影与 Workspace 保持一致。
- 更新莫兰迪主题的页面背景色。

## 1.1.4 — 2026-08-11

- 支持为浅色和深色模式分别设置默认主题。
- 左侧工作区支持应用内拖拽移动及拖到 Finder 复制。
- 恢复侧栏展开状态和活跃标签。
- 文件改为鼠标松开时打开，避免与拖拽冲突。
- 切换语言后原生界面即时刷新。

## 1.1.3 — 2026-08-10

- 修复不自动隐藏滚动条时编辑器滚动条过粗且颜色不随主题变化。
- 修复深色模式下编辑器加载完成时的白色闪烁。
- 退出时自动清理 7 天前的日志。
- 新增「更新内容」菜单（在编辑器窗口内打开）。
