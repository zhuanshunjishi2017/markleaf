MarkLeaf 更新内容
================
版本：v1.1.1.0
更新时间：2026-8-9

本次更新：重写更新内容

历史更新：

编辑

- 可视化编辑 Markdown，支持标题、加粗、斜体、删除线、行内代码、链接、图片，
  有序列表、无序列表、任务列表、引用块、代码块、水平线、表格
- 源码模式（纯文本），可切换回可视化模式
- 查找和替换，支持大小写匹配、全词匹配
- 撤销/重做
- 剪贴板图片粘贴、拖入图片

界面

- 系统原生菜单栏
- 侧边栏：工作区文件树、文档大纲
- 状态栏：字数、行列位置、编码、换行符、编辑模式、缩放百分比

文件

- 新建、打开、保存、另存为
- 打开文件夹作为工作区
- 安全保存（先写临时文件再替换）
- 自动恢复（崩溃后重新打开可恢复）
- 检测外部修改（提示而非静默覆盖）
- 自动保存（可选）
- 最近文件和最近文件夹记录

主题

- 内置 17 种颜色主题
- 1内置 0 种排版样式
- 跟随系统颜色模式自动切换
- 可导入自定义主题 CSS 文件
- 深色模式下菜单栏同步变深

导出

- 导出为 PDF（可选纸张大小、方向、页边距）
- 导出为 HTML
- 导出时保留颜色主题和排版样式

多语言

- 简体中文
- 繁體中文
- English
- 日本語

首选项

- 启动操作、保存选项、换行风格、历史记录
- 排版样式、配色方案、颜色模式、窗口置顶、隐藏滚动条、菜单栏样式
- 编辑器字体/行高/宽度设置、中文字体和西文字体独立选择
- 图片保存方式和默认目录

安装

- 提供 MSI 安装包
- 支持 x64、x86、arm64


修复

- 快捷键在编辑器获得焦点时失效
- 中文输入法导致文字重复和光标跳转
- 外部修改文件被静默覆盖
- 深色模式下状态栏颜色覆盖不全
- PDF 导出页边距为白色
- 不自动隐藏滚动条时编辑器滚动条过粗
- 切换语言后部分提示文字显示异常
