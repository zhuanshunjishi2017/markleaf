# MarkLeaf 更新内容

## v1.1.0

???+ info "2026年8月"
    国际化、多语言支持与界面打磨。

### 新增

- **多语言支持**：新增英文（en-US）、日文（ja-JP）、繁体中文（zh-TW）界面语言，可根据系统语言自动选择，也可在首选项中手动切换。
- **深色菜单栏**：Windows 原生 HMENU 支持深色模式渲染，菜单栏可跟随系统颜色主题自动切换。
- **颜色主题系统**：内置 16 套编辑器配色方案，包括浅色（苹果蓝、薰衣草、薄荷、玫瑰、森林、墨水、浓缩咖啡、浅色高对比度、莫兰迪、莫兰迪青、泛黄书页、纯白）和深色（深色、纯黑、深海、莫兰迪深色、深色高对比度）主题。
- **排版样式扩展**：新增无衬线、衬线、现代网页、极简、报纸、杂志、笔记本、复古印刷、双栏印刷和 LaTeX 等排版风格。
- **首选项对话框重构**：全新的标签页式首选项界面，支持图像设置、编辑器行为、外观主题等分类管理。
- **图像设置**：支持配置默认图片目录、相对路径引用方式（可选 `./` 前缀）、图片上传配置。
- **导出功能增强**：导出对话框支持选择排版样式和配色方案，PDF 导出支持纸张、页边距、页眉页脚自定义。
- **自定义滚动条**：编辑器区域使用自定义绘制的滚动条，风格与整体界面统一。
- **侧边栏标签栏**：左侧边栏增加工作区/大纲标签切换，支持图标 + 文字标签。
- **右键上下文菜单**：编辑器内右键弹出格式菜单，支持粗体、斜体、标题、列表等常用格式。
- **自动恢复**：异常退出后自动检测未保存内容，启动时提供恢复、丢弃或对比选项。
- **拖放打开**：支持将 Markdown 文件拖入窗口打开。
- **恢复未保存文件**：文件菜单新增「恢复未保存文件」入口，可手动触发恢复流程。
- **历史功能**：最近打开的工作区和文件记录，支持快速重新打开。
- **缩放功能**：编辑器缩放比例记忆与快捷键（Ctrl+加号/减号/0）。
- **系统图标集成**：工作区文件树使用 Windows Shell 系统图标，高 DPI 自适应。

### 修复

- 修复 Ctrl+Z/Y 撤销重做快捷键在焦点切换时的重复触发问题。
- 修复图标在高 DPI 下模糊的问题。
- 修复关于对话框和快捷键对话框显示异常。
- 修复右键上下文菜单高亮状态不正确的问题。
- 统一 i18n 本地化 key 命名，删除未使用的 CSS 样式文件。

## v1.0.0

???+ info "2026年7月"
    MarkLeaf 首个完整功能版本。

### 核心功能

- **所见即所得 Markdown 编辑**：基于 Tiptap/ProseMirror 编辑器内核，支持 CommonMark 和 GFM 语法。
- **源码模式**：内置 CodeMirror 6，可在可视化编辑和 Markdown 源码之间即时切换。
- **工作区管理**：支持打开文件夹、文件树浏览、大纲导航和外部修改检测。
- **多窗口**：支持打开多个彼此隔离的窗口实例。
- **查找替换**：文档内全文查找和替换，支持大小写敏感和全词匹配。
- **GFM 表格**：完整的表格编辑支持，包括行列增删、对齐设置。
- **任务列表**：支持 GFM 风格任务列表。
- **图片处理**：粘贴/拖入图片自动复制到文档资源目录，支持旋转和尺寸元数据。
- **PDF/HTML 导出**：一键导出为 PDF 或 HTML。
- **安全保存**：原子写入 + 临时文件，防止内容丢失；外部修改检测，拒绝静默覆盖。
- **原生界面**：Windows 原生 HMENU 菜单、系统标题栏、PerMonitorV2 高 DPI 支持。
