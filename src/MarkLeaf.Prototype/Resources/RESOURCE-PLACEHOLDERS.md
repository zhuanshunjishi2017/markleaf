# MarkLeaf 应用资源占位

阶段 0 不引入正式图片、图标或品牌资源。后期资源应放在以下位置：

- `Resources/App/App.ico`：应用图标，包含 16、20、24、32、40、48、64、128、256 px。
- `Resources/Toolbar/Light/`：浅色工具栏 SVG 源文件与 16/20/24/32 px PNG。
- `Resources/Toolbar/Dark/`：深色资源，推迟到后续版本。
- `Resources/Bitmaps/`：空状态或帮助插图；MVP 暂不需要。
- `Resources/ResourceManifest.json`：正式资源清单。
- `Resources/Licenses/Icons.txt`：图标来源、版本和许可证。

当前原型使用文字按钮，文件树未来使用 Windows Shell 图标，不提供临时假图标。
