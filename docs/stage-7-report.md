# MarkLeaf 阶段 7 报告

## 范围

阶段 7 实现工作区文件树、最近项目、基本文件操作、文档大纲和 Windows Shell 文件图标。

## 已完成

- “文件 > 打开文件夹”启用，支持选择工作区并在下次启动时恢复。
- “最近项目”保存最多 8 个有效文件夹并可直接重新打开。
- “文件 > 关闭文件夹”会停止加载和 watcher、清空当前工作区并隐藏左侧栏；用户重新显示侧栏时会看到“暂未打开工作区”。
- 工作区文件树使用 WinForms `TreeView`，目录仅在展开时异步枚举，只显示子目录和 `.md` 文件，文件夹优先并按名称排序。
- 隐藏和系统条目默认不显示；无法访问或扫描中消失的条目不会中断整个工作区。
- 双击文件复用现有未保存确认与安全文档打开流程。
- 工作区右键菜单支持新建 Markdown 文件、新建文件夹、重命名和移到回收站。
- 新建操作使用 `CreateNew`，不会静默覆盖同名文件；名称经过当前目录边界校验。
- 工作区 `FileSystemWatcher` 只作为刷新信号，500 ms 防抖后重新枚举已展开目录。
- 大纲数据直接来自编辑器 AST，包含标题级别、文本和 ProseMirror 位置；宿主不使用正则重复解析 Markdown。
- 大纲 `TreeView` 按标题级别构建层级，单击或按 Enter 跳转到对应标题；标题对齐编辑区顶部，并以黄色底色短暂高亮后渐隐。
- 编辑器光标移动和页面滚动会同步选择当前大纲节点。
- 文件和文件夹图标通过 `SHGetFileInfoW` 获取并按扩展名缓存。
- `ImageList` 按 DPI 使用 16、20、24 或 32 px 尺寸，显示器 DPI 变化后重建。

## 自动验证

- 工作区扫描测试覆盖目录优先排序、隐藏文件过滤和 1000 文件目录。
- watcher 防抖测试覆盖重复事件合并。
- 设置测试覆盖阶段 2 到阶段 3 迁移、最后工作区和最近项目往返。
- 编辑器协议测试覆盖带 AST 位置的大纲和大纲选中同步消息。
- Shell 图标尺寸测试覆盖 100%、125%、150% 和 200% DPI。

## 人工验收重点

- 大型目录展开期间主窗口应保持响应。
- 新建、重命名和移到回收站后，文件树应在防抖后更新。
- 大纲点击跳转、光标移动和页面滚动同步应保持稳定。
- 在 100%、125%、150% 和 200% 缩放下检查文件图标清晰度与行高。
