# 段落块句柄开关与可视化表格选择器设计

## 目标

为 macOS 版 MarkLeaf 增加两个与编辑体验相关的能力：

1. 在偏好设置中控制“段落块句柄”的显示，默认开启，保持升级前行为。
2. 将固定 `3×3` 表格插入改为 Word 风格的可视化行列选择器，并在顶部“表格”菜单和编辑区右键菜单中提供一致入口。

## 用户体验

### 段落块句柄

- 设置位置：`偏好设置 → 编辑器 → 可视化`。
- 设置名称：`显示段落块句柄`。
- 默认值：开启。
- 变更即时作用于当前编辑器；关闭时隐藏所有块句柄和当前块高亮，但不删除段落操作命令。
- 设置写入现有 `settings.json`，缺少该键的旧配置按开启处理。

### 表格选择器

- 顶部“表格”菜单和右键菜单均使用同一原生 AppKit 网格视图。
- 初始网格覆盖 `1×1` 到 `10×10`；鼠标移动时按矩形区域高亮。
- 网格标题实时显示当前尺寸，例如 `7×8 表格`。
- 点击尺寸后立即插入表格；保持当前语义，第一行作为表头。
- `Esc` 或菜单取消会关闭选择器且不修改文档。
- 提供“自定义表格…”入口，允许输入超过 `10×10` 的正整数行列数。
- 插入失败时关闭选择器并保持文档不变，由前端返回的命令状态负责现有错误处理。

## 架构与数据流

### 设置链路

1. `AppSettings` 增加 `showParagraphBlockHandle: Bool = true`，解码缺键时回退 `true`。
2. `PreferencesWindowController` 在编辑器页创建并初始化复选框，在 `controlChanged()` 中持久化。
3. 设置变化后沿用现有 `onSettingsChanged` 回调，当前 `EditorSession` 调用前端设置命令，所有已打开窗口刷新。
4. `EditorWeb` 的块句柄扩展增加可变的显示状态；隐藏时不创建句柄 decoration，重新开启时按当前光标状态恢复。

### 表格插入链路

1. 抽取一个可复用的 `TableSizePickerView`，负责网格绘制、鼠标跟踪、高亮、键盘取消和选择回调。
2. 原生菜单在“插入表格”位置挂载该自定义视图；右键菜单复用同一视图/工厂，避免两处行为分叉。
3. 选择结果通过原生命令传递 `rows` 和 `cols`，不再使用无参数的固定命令。
4. 前端 `executeEditorCommand` 的 `insertTable` 读取参数并调用 `chain.insertTable({ rows, cols, withHeaderRow: true })`。
5. 参数缺失、非有限数值或小于 1 时回退为 `3×3`，并对自定义输入做正整数校验和合理上限保护。

## 组件边界

- `AppSettings` 只负责值、默认值和 Codable 兼容，不持有 UI 或 WebView 引用。
- `PreferencesWindowController` 只负责设置控件和保存，不直接操作 ProseMirror。
- `EditorSession` 负责把设置和表格尺寸转换为 WebView 命令。
- `TableSizePickerView` 只负责尺寸选择，不负责文档插入。
- `EditorWeb` 只负责验证参数并执行 ProseMirror 表格命令。

## 测试策略

### Swift

- 设置解码测试：旧 JSON 缺少 `showParagraphBlockHandle` 时为 `true`；显式 `false` 能保留。
- 偏好设置行为测试：切换复选框会持久化并触发当前会话刷新。
- 表格尺寸模型测试：默认值、边界值、无效输入和自定义尺寸校验。

### TypeScript

- `insertTable` 使用指定行列数调用真实编辑器命令。
- 缺失/无效参数回退 `3×3`。
- 句柄显示状态关闭时不产生 widget decoration，重新开启后恢复。

### 回归

- 运行全部 EditorWeb Vitest 测试。
- 运行 macOS Swift 测试和现有设置/上下文菜单测试。
- 手动验证顶部菜单、右键菜单、网格 hover、取消、`10×10` 和自定义尺寸插入。

## 非目标

- 本次不改变表格编辑、删除、增删行列和对齐命令。
- 本次不新增表格样式、边框颜色或单元格合并 UI。
- 本次不把表格选择器迁移到 WebView 工具栏。
