# macOS 1.1.7 Windows 4d22f28 Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Windows `4d22f28` 的 v1.1.6 功能完整移植到 macOS，并将版本号更新为 1.1.7。

**Architecture:** 共享前端增加 ProseMirror 块句柄和命令，通过现有 WebView 协议通知宿主；macOS 使用 AppKit 原生菜单和侧栏搜索模型，保留现有格式刷与文档生命周期实现。样式资源从共享 Windows CSS 定向同步到 macOS 资源。

**Tech Stack:** TypeScript, Tiptap/ProseMirror, WKWebView bridge, Swift/AppKit, XCTest, Vitest, SwiftPM.

## Global Constraints

- 不删除 `src/EditorWeb/src/format-painter.ts` 或其 macOS 兼容行为。
- 搜索结果点击后立即退出搜索并打开文档。
- 工作区搜索只处理 `.md` 与 `.txt`，跳过隐藏/系统/符号链接目录。
- 所有新用户可见文案必须进入四语言本地化表。
- 版本目标为 `1.1.7`。
