# MarkLeaf 阶段 6 报告

## 范围

阶段 6 完成 GFM 表格、任务列表和图片资源工作流。图片只从受控的文档资源目录加载；关闭文档或应用绝不会清理图片，资源清理只能由用户显式执行。

## 已完成

- GFM 表格：插入表格、增删行列、删除表格、左/中/右对齐、表头渲染和 Tiptap 原生 Tab 导航。
- 任务列表：菜单切换、复选框交互、嵌套、Enter/Backspace 列表行为和 Markdown 往返。
- 图片粘贴与拖入：支持 PNG、JPEG、GIF、WebP、BMP，单文件限制 50 MiB；拒绝 SVG、扩展名伪装和不匹配的文件签名。
- 未保存文档使用按 document GUID 隔离的草稿目录；首次保存与另存为复制到 `<文档名>.assets` 并处理重名。
- 保存成功后才切换编辑器资源映射和 Markdown 相对路径；内部路径同步不增加 dirty revision，也不进入撤销历史。
- 迁移或保存失败会删除本轮新复制的文件，原资源和草稿不自动删除。
- “文件”菜单提供“清理未引用资源”，仅在用户确认后永久删除当前文档资源目录中的未引用图片。
- WebView2 仅将 `assets.local` 映射到当前受控资源目录；Markdown 中仍保存相对路径。

## 已知边界

- MVP 不支持合并单元格、多段落单元格或 Excel 级交互。
- 表格仅剩最后一行或最后一列时，删除命令会被 Tiptap 拒绝以避免损坏；使用“删除表格”移除整个表格。
- 图片清理按用户最终保留的文档版本判断引用，只处理当前文档受控资源目录中的支持格式图片。
- 草稿资源不会自动清理；恢复与生命周期清理将在后续恢复阶段统一设计，避免误删用户内容。

## 人工验收反馈修复

- 修复图片粘贴提示成功但编辑区不显示：图片插入改为带请求 ID 的命令，宿主等待编辑器返回实际插入结果后才提示成功。
- 修复运行时切换 `assets.local` 映射可能不作用于当前页面：宿主现在拦截图片请求，并只从当前文档受控资源目录安全返回文件。
- 修复资源管理器拖放显示禁用符号：启用 WebView2 外部拖放，并使用 `postMessageWithAdditionalObjects`/`CoreWebView2File` 获取真实文件路径，不再依赖浏览器中不可用的 `File.path`。
- 剪贴板粘贴会优先识别文件列表；其中支持的图片文件按图片导入，随后才处理位图或文本。
- “段落”菜单新增“插入图片...”，支持一次选择多张图片。
- 拖放坐标在 WebView2 页面中由 ProseMirror `posAtCoords` 解析，图片插入鼠标释放位置而非旧焦点位置。
- 已回滚关闭时自动清理：关闭、放弃保存或正常退出均不会删除 `.assets` 中的任何文件。
- 恢复“文件 > 清理未引用资源”菜单命令；仅对已保存且没有未保存修改的文档开放清理流程，二次确认后使用 `File.Delete` 直接永久删除，不经过回收站。
- 图片节点选中后显示四个角的缩放手柄；拖动时保持宽高比，并在释放鼠标时提交一次可撤销的尺寸变更。
- “段落”菜单新增“顺时针旋转图片”，仅在选中图片节点时启用；每次旋转 90 度，支持撤销与重做。
- 图片宽度、高度和旋转角度通过保留的 `markleaf:` 图片标题元数据写入 Markdown，普通图片标题保持不变，保存并重新打开后可恢复。
