# MarkLeaf 阶段 8 报告

## 范围

阶段 8 实现当前文档查找替换、CodeMirror 6 源码模式和独立多窗口实例，不开发多标签页。

## 已完成

- 编辑区内置查找栏，支持向前/向后、区分大小写和全词匹配。
- 替换模式支持替换当前匹配和全部替换，并显示匹配或替换数量。
- 可视化编辑器与源码编辑器共用 Markdown 快照；切换前同步当前内容，切回时重新解析 Markdown。
- 源码模式使用 CodeMirror 6，支持行号、换行、Markdown 语法和独立撤销历史。
- 菜单中的查找、替换和源码模式命令已启用，源码模式勾选状态和状态栏模式文字同步更新。
- 文件菜单新增“新建窗口”和“在新窗口中打开”。
- 工作区文件右键菜单支持在新窗口中打开。
- 新窗口使用独立进程，每个窗口只承载一个活动文档，天然隔离 WebView2、revision、dirty 状态、文件监控和保存流程。
- 同一文件被多个窗口打开时不做实时同步；后保存的窗口仍由现有文件指纹检查阻止静默覆盖。
- 多实例设置写入改用进程和 GUID 隔离的临时文件，避免共享固定 `.tmp` 名称。
- 修复菜单状态二次校验，使查找、替换和源码模式在编辑器就绪后保持可用。
- 日志文件按进程 ID 隔离，避免第二窗口因日志文件写锁在启动阶段退出。
- 查找替换栏改为上下两行布局，所有操作按钮位于输入区下方。
- 可视化模式查找使用 ProseMirror 装饰高亮，不再改变文档选区；查找后焦点保持在查找或替换输入框。
- 菜单栏和编辑器右键菜单的复制、剪切、粘贴命令已接通；右键菜单常用命令使用括号访问键提示，不显示 `Ctrl+*`。
- 新增“复制为 Markdown 源码”和“复制为纯文本”。可视化模式普通复制/剪切写入带格式 HTML 和纯文本回退，另两项分别导出 Markdown 与无格式文本；源码模式三种复制均导出所选源码。
- 可视化模式粘贴优先读取并清理 HTML，源码模式始终按纯文本替换当前选择。
- 剪贴板命令状态按实际上下文刷新：无文本选择时复制/剪切禁用；剪贴板无文本、HTML、图片或文件时粘贴禁用；其余情况保持可用。

## 已知限制或风险

- 可视化与源码模式切换会重建编辑器，因此两种模式的撤销历史彼此独立。
- CodeMirror 当前和可视化编辑器打入同一前端 chunk，压缩前约 1 MB；后续性能阶段应评估动态加载源码模式。
- 多窗口不提供同文件实时同步，冲突在保存时提示处理。
- 多 DPI、输入法和复杂 Markdown 的源码模式体验仍需人工验收。

## 请开发者检查

1. 使用 `Ctrl+F`、`Ctrl+H` 验证复杂文档中的查找替换、大小写和全词行为。
2. 从“视图 > 源码模式”多次切换，确认内容没有丢失，并检查解析失败或不受支持语法的表现。
3. 使用“文件 > 新建窗口”“在新窗口中打开”及工作区右键入口，确认窗口之间互不影响。
4. 在两个窗口打开同一文件并依次保存，确认后保存窗口不会静默覆盖前一窗口的内容。
5. 在可视化模式分别用菜单栏和右键菜单验证复制、剪切、粘贴，以及“复制为 Markdown 源码”“复制为纯文本”；将普通复制粘贴到支持富文本的应用，确认格式保留。
6. 在源码模式验证三种复制结果完全相同，并确认菜单剪切和粘贴只修改当前源码选择。
