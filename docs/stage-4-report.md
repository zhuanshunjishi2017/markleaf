# MarkLeaf 阶段 4 报告

## 范围

阶段 4 完成单文档的新建、打开、编辑状态跟踪、安全保存、另存为、关闭确认和磁盘外部修改检测。自动恢复、工作区、多文档和最近文件仍按计划留在后续阶段。

## 实现

- `MarkdownDocument` 保存文档 ID、路径、Markdown、编码、BOM、换行、dirty、只读、revision、写入时间和内容指纹。
- 打开文件支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM，并对常见无 BOM UTF-16 文本进行检测。
- 保存保留原编码、BOM 和主要换行风格；新文档默认 UTF-8 无 BOM 和 Windows 换行。
- 未修改的已有文档执行“保存”时不请求序列化、不重写磁盘文件。
- 保存前向 WebView2 请求带 request ID 和 revision 的最新快照。
- 安全保存先在目标同目录创建唯一临时文件，异步写入并 `Flush(true)`，随后使用 `File.Replace` 或同目录移动完成替换。
- 保存失败不截断原文件；若替换阶段失败，提示可恢复临时文件的位置。
- 保存前比较 SHA-256 内容指纹，时间戳相同但内容不同也会识别为外部修改。
- 外部冲突提供重新加载、并排比较、另存为、明确强制覆盖和取消，不会静默覆盖。
- `FileSystemWatcher` 只作为防抖后的重新检查信号，不直接驱动重载；存在未保存修改时绝不自动重载。
- 新建、打开、保存、另存为和关闭流程已接入原生菜单及统一快捷键命令。
- 标题栏使用 `*文件名 - MarkLeaf` 表示未保存修改，状态栏显示文件操作状态。
- 日志只记录脱敏后的文件名和格式元数据，不记录文档正文。

## 人工验收建议

1. 使用 `Ctrl+O` 打开 UTF-8、UTF-8 BOM、CRLF 和 LF 文件，确认显示正常。
2. 编辑后观察标题栏出现 `*`，使用 `Ctrl+S` 保存，确认 `*` 消失且格式保持。
3. 使用 `Ctrl+Shift+S` 保存为新文件或无扩展名文件。
4. 修改后关闭窗口，分别检查保存、不保存和取消。
5. 打开文件后用其他编辑器修改磁盘版本，检查无本地修改时的重新加载提示。
6. 同时保留本地未保存修改和外部修改，再保存，检查重新加载、比较、另存为、强制覆盖和取消。
7. 打开只读文件并保存，确认转入“另存为”，原文件不被破坏。

## 阶段边界

本阶段不实现自动恢复文件、崩溃恢复 UI、文件夹工作区、多文档标签页、最近文件和源码模式。这些能力不会在阶段 4 验收前提前引入。
