# MarkLeaf 阶段 6.5 报告

## 范围

阶段 6.5 补全编辑器状态栏与编辑区原生右键菜单，不包含阶段 7 的工作区和大纲功能。

## 已完成

- 状态栏持续显示操作提示、非空白字符数、选中字符数、当前块类型、光标行列、文档编码、换行格式和可视化模式。
- 中文输入法组合期间暂停状态更新，组合结束后统一刷新。
- 当前块类型覆盖正文、1 至 6 级标题、引用、代码块、三种列表、表格和图片。
- 编辑区右键菜单使用 Win32 原生 `HMENU`，包含粗体、斜体、正文、标题子菜单、列表子菜单、剪切、复制和粘贴。
- 右键菜单不显示快捷键提示；启用、禁用和勾选状态复用统一命令路由。
- 无选区时，从右键菜单执行粗体或斜体会作用于光标所在文本块，并在完成后恢复光标。
- 修复 WebView2 CSS 坐标到 Win32 屏幕坐标的 DPI 换算，覆盖 100%、125%、150% 和 200% 缩放。
- 操作提示统一使用“已执行：中文命令名”，不显示英文枚举名称。
