# MarkLeaf 更新履歴

## 1.1.7 — 2026-08-13

- サイドバーで Markdown/TXT ファイルを名前または内容から検索し、アウトライン見出しを絞り込めます。
- 段落ブロックハンドルのネイティブ操作メニューと、段落前後への行挿入を追加しました。
- タスクリストのチェックボックスを整列し、日本語印刷では Yu Mincho/Yu Gothic を使用します。

## 1.1.6 — 2026-08-12

- 外部から開いたファイルを新規ウィンドウまたは現在のウィンドウで開く設定を追加。すでに開いているファイルは重複せず、対応ウィンドウをアクティブ化します。
- 変更済みドキュメントを閉じる・置き換える・終了する際に、保存／保存しない／削除／キャンセルを確認。該当設定が有効で書き込みに成功した場合のみ自動保存します。
- 「書式」メニューとエディタのコンテキストメニューに、1 回限りの「書式のコピー/貼り付け」を追加。
- 4 つのインターフェース言語で Markdown 更新履歴を提供。
- 復元ダイアログを完全にローカライズ。
- 「アウトライン」のフォントサイズとグレーの選択背景を「ワークスペース」と統一。
- 「アウトライン」の選択が最初のクリックで表示されるよう修正。
- 言語切り替え後も環境設定の現在のページとウィンドウ位置を維持。

## 1.1.5 — 2026-08-12

- 簡体字・繁体字・日本語・韓国語の字形を選べる「CJK 優先フォント」を追加
- 表示メニューに「フォーカスモード」を追加（F11 で開始、Esc で終了）
- エディタのフォント設定を専用の「フォント設定」ダイアログに統合
- セリフ・サンセリフスタイルに Source Han/Noto CJK フォントのフォールバックを追加
- アウトラインのフォントサイズとグレーの選択影をワークスペースと統一
- モランディテーマのページ背景色を更新

## 1.1.4 — 2026-08-11

- ライト／ダークモードそれぞれに既定テーマを設定可能に
- 左のワークスペースでドラッグ移動、Finder へのドラッグでコピーに対応
- サイドバーの展開状態とアクティブなタブを復元
- ドラッグとの競合を避けるため、ファイルはマウスを離したときに開くよう変更
- 言語切り替え後、ネイティブ UI を即時更新

## 1.1.3 — 2026-08-10

- スクロールバーの自動非表示がオフのとき、エディタのスクロールバーが太すぎてテーマ色が反映されない問題を修正
- ダークモードでエディタの読み込み完了時に白くちらつく問題を修正
- 終了時に 7 日前のログを自動クリーンアップ
- 「更新内容」メニューを追加（エディタウィンドウ内で開く）
- バージョンを 1.1.3 に更新
